# Нагрузка: что клон выдержит и что сломается первым

Ресёрч 2026-10-30 по вопросу владельца «насколько хорошо приложение будет держать нагрузку». Код не менялся. Из вариантов сделан первый для квоты Tracestrack — подложка по умолчанию OpenFreeMap Outdoor с откатом на Tracestrack: архив [openfreemap-default-basemap](../changes/archive/2026-10-30-openfreemap-default-basemap/design.md). Цены и лимиты Cloudflare здесь не повторяются: [security-audit.md](security-audit.md), «Цены и как считаем», п. 1 и п. 7; схема лимитов — [protection.md](../../docs/architecture/protection.md).

## Коротко

- Свой бэкенд — не узкое место. Cloudflare масштабирует Pages, Worker'ы и R2 сам; заход стоит ≈ 135 запросов к Worker'ам и Functions, план Workers Paid включает 10 млн в месяц — ≈ 70 тыс. активных заходов, дальше ≈ $0.04 за тысячу заходов.
- Первым ломается **квота Tracestrack** (подложка по умолчанию): 100 тыс. тайлов в месяц — **≈ 900 активных заходов с десктопа** (107 тайлов) или ≈ 2 800 коротких (35 тайлов при открытии). Дальше — откат на OSM с тостом до конца месяца.
- Вторым — **OSM как запасная подложка**: тайлы идут из браузеров прямо на `tile.openstreetmap.org`, а правила OSMF запрещают интенсивное использование приложением без разрешения и разрешают блокировку без предупреждения.
- Третьим — **лимиты на IP** у групп за одним адресом (офис, турклуб на одном Wi‑Fi, мобильный CGNAT): прокси даёт 1 200 тайлов в минуту на IP, активное движение карты — ≈ 300 тайлов в минуту, то есть ≈ 4 человека одновременно. Cloudflare сам не советует ключ по IP.
- У пользователя — память: движок в браузере 0.6–0.8 ГБ на вкладку ([system-design-audit.md](system-design-audit.md), «Решения без записанной причины»).

## Замеры

### Трафик прода, 2026-10-23 – 2026-10-30

GraphQL Analytics аккаунта: прокси ≈ 9 500 запросов (CPU p50 0.6 мс, p99 2 мс), Pages Functions 1 860, API высот 58 (CPU p50 24.5 мс, p99 115 мс), треки 54. Это владелец и несколько тестеров: нагрузки под замер на проде нет.

### Тайлы подложки на заход

Сборка клона с подменённой сетью (фикстура `network` e2e, квота не тратится), сессия «открыть вид по умолчанию, два приближения колесом, четыре сдвига на 250–300 px, три отдаления», считаются разные адреса тайлов `Tt`:

| Экран | При открытии | За сессию |
|---|---|---|
| Десктоп 1440×900 | 35 | 107 |
| iPhone 13 (эмуляция) | 9 | 36 |

Ретина берёт тайлы `@2x` той же сетки — тот же кредит квоты. Сессия заняла ≈ 20 с действий, то есть ≈ 300 тайлов в минуту при активном движении. Браузер кеширует тайл на сутки (`Cache-Control: public, max-age=86400` прокси, [tracestrack.js](../../workers/cors-proxy/src/tracestrack.js)); кеша на краю Cloudflare нет: Cache API на `*.workers.dev` не работает (design [add-outdoor-basemap](../changes/archive/2026-10-09-add-outdoor-basemap/design.md)), так что каждый промах кеша браузера — кредит Tracestrack.

### Прокладка на проде

Playwright, headless Chromium, прод `nakarte-routing.pages.dev`, подложка OpenFreeMap (`l=Of`), пешая активность, три коротких маршрута в Тбилиси (тайл BRouter `E40_N40.rd5`):

| | Запросов к Functions | Байт | Время |
|---|---|---|---|
| Прогрев движка при выборе активности | 3 | ≈ 0 | — |
| Первый маршрут | 21 (11 к `/brouter-wasm/`: jar'ы и профили; 10 к `/tiles/`) | ≈ 2.4 МБ | 4.2 с |
| Второй и третий маршрут | 1 на оба | 128 КБ | ≈ 0.55 с |

JDK CheerpJ (≈ 43 МБ, CDN Leaning Technologies) грузится из чужого iframe и в счёт не попал ([AGENTS.md](../../AGENTS.md), «Движок в браузере»). Оценка design [limit-pages-functions](../changes/archive/2026-10-08-limit-pages-functions/design.md) «≈ 40 запросов на маршрут» верна для холодного движка; тёплый тратит единицы.

## Модель захода и пороги

Активный заход с десктопа: 107 тайлов `Tt`, первый маршрут и ещё два, один профиль высот — ≈ 107 + 25 + 1 ≈ 135 запросов к Worker'ам и Functions (вызовы `nakarte-guard` по service binding не тарифицируются).

| Ресурс | Лимит | Порог |
|---|---|---|
| Tracestrack, бесплатный тариф | 100 тыс. кредитов в месяц, некоммерческое использование | ≈ 900 активных десктопных / ≈ 2 800 телефонных или коротких заходов в месяц |
| Workers Paid, запросы | 10 млн в месяц включено, дальше $0.30 за млн | ≈ 70 тыс. активных заходов в месяц; 1 млн заходов ≈ +$40 |
| R2 класс B (тайлы BRouter, высоты) | 10 млн в месяц включено | ≈ 10–20 чтений на заход — сотни тысяч заходов |
| Прокси, тайлы слоёв | 1 200 в минуту на IP в одном дата-центре Cloudflare | ≈ 4 человека за одним IP, одновременно двигающих карту |
| Pages Functions | 1 200 в минуту на IP на обе функции | ≈ 50 человек за одним IP, одновременно делающих первый маршрут |
| API высот | 60 в минуту на IP | профиль перестраивается раз в секунду правок — ≈ 10–20 человек с открытым профилем за одним IP |
| Sentry Developer | 5 тыс. ошибок в месяц | одна массовая ошибка |
| Tracestrack `Origin` | глобального счётчика нет | квоту может выбрать любой не-браузер с поддельным `Origin` ([add-outdoor-basemap](../changes/archive/2026-10-09-add-outdoor-basemap/design.md), «Риски») |

Лимит частоты Workers считается отдельно в каждом дата-центре и приблизительно ([Rate Limiting](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/), «Locality», «Accuracy»); Cloudflare там же не советует ключ по IP: «many users may share a single IP, especially on mobile networks».

## Узкие места и варианты

### 1. Квота Tracestrack

- Тариф Personal — €3.99 в месяц за 250 тыс. кредитов (design [add-outdoor-basemap](../changes/archive/2026-10-09-add-outdoor-basemap/design.md), «Риски», цены на 2026-10-09 — сверить на tracestrack.com перед решением): ≈ 2 300 активных заходов. Решение владельца.
- Кеш тайлов на краю Cloudflare: Cache API есть у Pages Function (тот же origin, что сайт) и у Worker'а на своём домене, но не на `*.workers.dev`. Популярные места тратили бы кредит раз на дата-центр в сутки, а не раз на браузер. Условия Tracestrack о кешировании — проверить.
- Подложка по умолчанию без квоты: векторная OpenFreeMap Outdoor (`Of`) уже в каталоге; у публичного OpenFreeMap «no limits on the number of map views or requests», без ключа, коммерческое использование разрешено ([openfreemap.org](https://openfreemap.org/)). Цена — другой вид карты по умолчанию (решение владельца 2026-10-09 — Tracestrack).

### 2. OSM как запасная подложка

Откат `Tt` → `O` (`basemapFallback`, спека `map-layers`) переносит весь трафик подложки на `tile.openstreetmap.org`. Правила OSMF запрещают без разрешения Operations Working Group распространять приложение, которое интенсивно берёт тайлы с `tile.openstreetmap.org`, и разрешают блокировку без предупреждения ([Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/), 2026-10-30). Вариант — откат на `Of` вместо `O`: квоты нет, растровый вид теряется.

### 3. Лимиты на IP у групп

Лимиты задумывались против флуда с одного адреса ([security-audit.md](security-audit.md), п. 1), а не против группы людей за NAT. Варианты: поднять лимит прокси для хостов слоёв (цена флуда растёт линейно: $48 в месяц с IP при 1 200 в минуту, там же); считать тайлы `Tt` отдельным счётчиком; для Functions и высот — оставить, запас есть. Замерить реальные `429` можно только при трафике: Workers Logs `nakarte-cors-proxy` (спека `clone-monitoring`, «Журналы Worker'ов»).

### 4. Устройство пользователя

Не серверная нагрузка, но первым откажет на слабом телефоне: 0.6–0.8 ГБ на вкладку и холодный старт 5–6 с. Варианты движка — backlog, «Варианты движка в браузере».

### 5. Бесплатные чужие сервисы

Поиск mapy.cz через недокументированную ручку и публичный photon, сессия Strava, режим Google без ключа, CDN CheerpJ (лицензия Community — личные и некоммерческие проекты, [cheerpj.com/docs/licensing](https://cheerpj.com/docs/licensing)): лимиты не опубликованы, при росте могут закрыться без предупреждения. Список и решения — backlog, «Внешние зависимости и риски».

## Как следить, когда трафик появится

- Заходы — Cloudflare Web Analytics проекта Pages (`AGENTS.md`, «Публичный клон на Cloudflare»); сравнивать с порогом Tracestrack из таблицы.
- Квота — ежедневный `tracestrack check` (письмо на `503`); `429` и отказы — Workers Logs прокси; ошибки пользователей — Sentry.
- Деньги — бюджетные оповещения Cloudflare ([security-audit.md](security-audit.md), п. 7).
