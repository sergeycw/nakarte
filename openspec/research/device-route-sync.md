# Отправка маршрута в COROS, Wahoo, Garmin

Ресёрч 2026-10-12 по пункту backlog «Отправка маршрута прямо в приложение часов и велокомпьютера» (запрос пользователя, переданный владельцем): может ли клон без своих аккаунтов отправить маршрут сразу в облако COROS, Wahoo или Garmin, чтобы он дошёл до устройства, и что делать, если не может. Сейчас есть только файлы: «Save as GPX», «Save as GPX with elevation», «Save as KML» (`web/src/tracks/export.ts`). Факты — по первоисточникам, ссылка у каждого; справки COROS и Wahoo на обычный запрос отвечают `403` или проверкой Cloudflare, их статьи читались через API справочного центра Zendesk (`/api/v2/help_center/en-us/articles/<id>.json`), даты статей — оттуда; статьи Garmin Support (на `curl` тоже `403`) — в браузере. Решения владельца помечены **[владелец]**, рекомендации агента — **[агент]**. Change переносит свои решения в свой design; документ остаётся справкой.

## Итог

Решения владельца 2026-10-12 **[владелец]**: делать change `send-route-to-device` — маршрут файлом в приложение устройства; заявку в Wahoo Cloud API не подавать сейчас; в COROS не писать.

- Прямой отправки для нас нет ни у кого **[агент]**. Garmin Courses API — только для бизнеса, и программа сейчас не принимает заявки. COROS отдаёт `route/push` только партнёрам с зарегистрированной компанией, а самообслуживаемый вход COROS маршрутов не умеет. Wahoo Cloud API технически подходит (PKCE без секрета, CORS открыт), но production — после ревью Wahoo, с privacy policy, атрибуцией и FIT-файлом, и маршрут дойдёт только до ACE, BOLT 3 и ROAM 3.
- Все три приложения штатно принимают GPX через «открыть в» на телефоне, а Garmin Connect — ещё и импортом на сайте. Этот путь и есть change: файл GPX с высотами, на iOS — шторка «Поделиться», иначе скачивание, и короткая инструкция по каждому бренду.
- Chrome на Android файл `.gpx` через Web Share не отдаёт (список разрешённых типов), там остаётся скачивание и «открыть в» из уведомления.

## Garmin

- Courses API программы Garmin Connect Developer публикует курсы в Garmin Connect, дальше пользователю достаточно синхронизировать устройство ([Courses API](https://developer.garmin.com/gc-developer-program/courses-api/)). Формат тела запроса и лимиты — в документации за входом на портал, не проверено.
- Доступ: «only for business use», ответ на заявку — за два рабочих дня, интеграция — 1–4 недели ([FAQ программы](https://developer.garmin.com/gc-developer-program/program-faq/)). Соглашение даёт лицензию «solely for internal business purposes» и право Garmin отозвать ключ в любой момент (§4.1, §4.2 [Agreement FRM-0952 Rev. B](https://developerportal.garmin.com/sites/default/files/Garmin%20Connect%20Developer%20Program%20Agreement.pdf)); по §4.5 и §5.3 — заметное уведомление со ссылкой на политику Garmin, явное согласие перед загрузкой и своё пользовательское соглашение.
- Заявки не принимаются: на всех страницах программы только «Stay tuned for more updates on the program» (там же, 2026-10-12). Что очередь заморожена с весны 2026, пишет только вторичный источник со ссылкой на ответ поддержки Garmin ([the5krunner, 2026-09-14](https://the5krunner.com/2026/09/14/garmin-developer-api-access-paused/)).
- Авторизация — OAuth 2.0 PKCE, но обмен кода и обновление токена требуют `client_secret`, а «CORS pre-flight requests (OPTIONS) are not supported» ([спецификация OAuth2 PKCE, 2025-07-23](https://developerportal.garmin.com/sites/default/files/OAuth2PKCE_1.pdf)): понадобился бы свой Worker с секретом и токенами пользователей.
- Без API: статья Garmin «Importing a Third-Party Course into Garmin Connect» принимает `.fit`, `.gpx` и `.tcx`; на телефоне — открыть файл и выбрать Connect (на iOS — Share → Garmin Connect), на сайте — Training & Planning → Courses → Import ([Garmin Support](https://support.garmin.com/en-US/?faq=wKuZXCaZRP4mWPX5aRz5h5)). Импортированный курс на устройство сам не уходит: «Send to Device» в приложении или Garmin Express; большинство устройств читает первые 15 символов названия и держит до 100 курсов ([Garmin Support](https://support.garmin.com/en-US/?faq=C4mcn2I4cGAL7vkq3qTCMA)).
- Ещё путь — своё приложение Connect IQ: `makeWebRequest` с `HTTP_RESPONSE_CONTENT_TYPE_GPX` или `_FIT` скачивает и разбирает курс на устройстве ([Communications](https://developer.garmin.com/connect-iq/api-docs/Toybox/Communications.html)); так делает Ride with GPS ([Garmin Support](https://support.garmin.com/en-US/?faq=NaHPJietLh1JONP2sz5DdA)). Нужны своё приложение на Monkey C, ревью магазина и Worker с маршрутами — не рассматривалось.

## Wahoo

- Cloud API: `POST https://api.wahooligan.com/v1/routes`, scope `routes_write`, файл — только «Base64 encoded FIT file»; обязательны `external_id`, `provider_updated_at`, `name`, `workout_type_family_id`, `start_lat`, `start_lng`, `distance`, `ascent`. «Routes imported by the Cloud API will not sync to the ELEMNT App. Routes will sync to the Wahoo App and directly to a ELEMNT bike computer» ([Cloud API](https://cloud-api.wahooligan.com/)). Wahoo app — для ACE, BOLT 3 и ROAM 3 ([Wahoo Support, 2026-09-08](https://support.wahoofitness.com/hc/en-us/articles/22710659712658)), старые ELEMNT, BOLT и ROAM работают с ELEMNT app ([Wahoo Support, 2024-09-30](https://support.wahoofitness.com/hc/en-us/articles/20582927265042)).
- Доступ: «Wahoo Fitness is currently limiting use of the API to those who request it»; sandbox и production — разные заявки, sandbox в production не переводится ([портал](https://developers.wahooligan.com/cloud)); production — после ревью Wahoo ([Cloud API](https://cloud-api.wahooligan.com/), «Registration»). Лимиты на приложение: sandbox — 25 за 5 минут, 100 в час, 250 в день; production — 200, 1000, 5000 (там же, «Rate Limiting»).
- Авторизация: есть PKCE для публичного клиента («Confidential?» = No, `S256`), в примерах обмена кода и обновления `client_secret` нет; access token живёт 2 часа (там же). `OPTIONS` на `/oauth/token` и `/v1/routes` с `Origin: https://nakarte-routing.pages.dev` отвечает `access-control-allow-origin: *` (`curl` 2026-10-12): весь поток, похоже, обходится без Worker'а, сквозь не проверялся.
- Соглашение: бесплатно сейчас, плату Wahoo может ввести; подписывает юрлицо или sole proprietor; обязательны privacy policy с GDPR и CCPA, удаление данных при отзыве доступа, атрибуция по Media Kit; нельзя использовать API в продукте, который «supports in any way a third party that provides services competitive to Wahoo's products» — решает Wahoo ([Wahoo API Agreement](https://www.wahoofitness.com/wahoo-api-agreement)). Сайт, который отдаёт файлы и для Garmin, формально под этот пункт может попасть **[агент]**.
- Без API: Wahoo app принимает FIT, GPX и TCX — скачать файл, выбрать Wahoo в «открыть в», затем My Routes → Send to ELEMNT; импорт идёт через облако Wahoo, нужен интернет ([Wahoo Support, 2026-07-08](https://support.wahoofitness.com/hc/en-us/articles/25936827245970)). ELEMNT app старых устройств принимает GPX, TCX и FIT так же (статья 2024-09-30 выше). ELEMNT MINI маршрутов не умеет ([Wahoo Support](https://support.wahoofitness.com/hc/en-us/articles/115001120510)).
- Из сайтов маршруты через Cloud API шлёт Bikemap; Komoot, Ride with GPS, Strava подключаются из самого Wahoo app ([Wahoo Support, 2026-08-19](https://support.wahoofitness.com/hc/en-us/articles/23022859474962)).

## COROS

- Partner API: «Registered company with authorized technical representative», «Established platform with demonstrated user base», согласие с COROS API Terms of Use (текст не публичный); OAuth 2.0 с Client ID и Secret; среди методов — `route/push (GPX/KML, 50MB max)`, лимит 1 000 вызовов в минуту; заявка — письмом на `api@coros.com` и формой ([Partner API Access, 2026-09-03](https://support.coros.com/hc/en-us/articles/53181766856724)). Сроки и цена не опубликованы.
- Тем, кто не подходит, COROS предлагает «Build on COROS MCP» — без заявки, но в ограничениях «No GPX route import/export» ([Build on COROS MCP](https://support.coros.com/hc/en-us/articles/53181619102996)).
- Без API: скачать GPX, выбрать COROS в «открыть в», Save, затем Explore → маршрут → Sync with Your Device ([COROS Support, 2026-06-23](https://support.coros.com/hc/en-us/articles/24181489692436)); нужен «standard GPX format» ([COROS Support](https://support.coros.com/hc/en-us/articles/360040243352)); GPX без высот приходит без высот ([COROS Support](https://support.coros.com/hc/en-us/articles/15405567227028)). На iOS импорт из iMessage сломан, обход — «Файлы» → Поделиться → COROS ([COROS Support, 2024-12-11](https://support.coros.com/hc/en-us/articles/8525385040148)). DURA берёт только велосипедные маршруты ([COROS Support](https://support.coros.com/hc/en-us/articles/15285167205268)); COROS советует меньше 200 точек маршрута ([DURA](https://support.coros.com/hc/en-us/articles/26895703330196)).
- Strava, Komoot, Ride with GPS и AllTrails подключаются из приложения COROS, маршруты забирает COROS ([список партнёров](https://support.coros.com/hc/en-us/articles/360040256531)).

## Файл в приложение: Web Share

- `navigator.share({files})` есть в Safari iOS и macOS с 14, Chrome Android с 76, Chrome desktop на всех ОС с 128; в Firefox Android файлов нет ([browser-compat-data](https://github.com/mdn/browser-compat-data/blob/main/api/Navigator.json)). Нужны HTTPS и свежее действие пользователя, иначе `NotAllowedError` ([W3C Web Share](https://w3c.github.io/web-share/)); WebKit и Chromium тратят это действие на вызов `share()`.
- Chromium отдаёт файл, только если и расширение, и MIME в списке разрешённых, а там нет `gpx`, `fit`, `xml` ([FILE_TYPES.md](https://source.chromium.org/chromium/chromium/src/+/main:third_party/blink/renderer/modules/webshare/FILE_TYPES.md)). `canShare({files})` в Chromium тип не проверяет: вернёт `true`, а `share()` упадёт с `NotAllowedError` ([navigator_share.cc](https://source.chromium.org/chromium/chromium/src/+/main:third_party/blink/renderer/modules/webshare/navigator_share.cc)). Обход через `.txt` и `text/plain` до приложений устройств, скорее всего, не дойдёт — не проверено.
- WebKit списка типов нет: файл уходит в `UIActivityViewController` под своим именем, тип — по расширению ([WKShareSheet.mm](https://github.com/WebKit/WebKit/blob/main/Source/WebKit/UIProcess/Cocoa/WKShareSheet.mm)). Есть ли Garmin Connect, Wahoo и COROS в шторке для `.gpx` из Safari — проверить на телефоне; COROS в шторке «Файлов» есть (статья 2024-12-11 выше).
- Документированных ссылок-схем, которые открывают приложение Garmin, Wahoo или COROS с файлом, не нашлось.

## FIT

GPX все три приложения принимают, FIT нужен только Wahoo Cloud API. Официальный `@garmin/fitsdk` умеет кодировать, но под «FIT Protocol License Agreement»: «internal business purposes», запрет распространения под лицензиями с открытым кодом (§2c, §2d [LICENSE.txt](https://github.com/garmin/fit-javascript-sdk/blob/main/LICENSE.txt)) — в MIT-бандл его не брать **[агент]**. Порядок сообщений файла курса: File Id (type 6) → Course → Lap → Event start → Record → Course Point → Event stop ([Course Files](https://developer.garmin.com/fit/articles/file-types/course.html)).

## Что решить в change

- Где пункт: меню трека и «Share track» редактора (`TrackExportItems.tsx`), название и одна инструкция на три бренда или выбор бренда.
- Файл — GPX с высотами (`exportGpxWithElevations`): COROS без `<ele>` теряет высоты. Запрос высот асинхронный, а `share()` требует свежего нажатия: сначала собрать файл, потом отдельная кнопка «Share» (или файл без высот при ошибке API высот).
- Заранее путь не выбрать без разбора `User-Agent`: `canShare` в Chromium отвечает `true` и для `.gpx`. Пробовать `share()`, на `NotAllowedError` и `TypeError` — кнопка скачивания тем же файлом; `AbortError` — пользователь закрыл шторку, ничего не делать.
- Проверить, что приложения принимают наш GPX: трек `trk` с фиктивным `time` 1970 года у точек (`toGpx`, ради старого импорта Garmin Connect); длинное название — Garmin видит 15 символов.
- Тесты: `navigator.share` — подмена в browser-тесте (проп `App`, как `writeClipboard`), сценарии «шторка», «отказ → скачивание», «отмена». Вид шторки и приложения в ней — только на телефоне владельца.
