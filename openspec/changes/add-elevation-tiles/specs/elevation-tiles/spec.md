# Spec Delta

## Purpose

Тайлы высот клона для показа высоты и уклона под курсором: сетка высот 256×256 на тайл в проекции Web Mercator, в формате, который читает клиент nakarte.

## ADDED Requirements

### Requirement: Формат тайла

`GET /{z}/{x}/{y}` для `z` от 0 до 11 SHALL отдавать `200` и тело из 256×256 значений Int16 little-endian построчно сверху вниз: первое значение — высота в метрах, каждое следующее — разность с предыдущим. Без данных значение SHALL быть `-512` до дельта-кодирования.

#### Scenario: Декодирование клиентом

- **WHEN** клиент делает префиксную сумму тела тайла
- **THEN** получает 65 536 высот в метрах, `-512` там, где данных нет

### Requirement: Значение пикселя

Высота пикселя SHALL быть высотой Copernicus GLO-30 в центре пикселя (билинейно по соседним узлам), округлённой до метра.

#### Scenario: Сверка с сервисом высот

- **WHEN** высота пикселя сравнивается с ответом сервиса высот для координат центра пикселя
- **THEN** разница не больше 1 м

### Requirement: Тайл без данных

Тайл, в котором нет ни одного пикселя с данными (море), и тайл с `z` больше 11 SHALL получать `404`.

#### Scenario: Тайл над океаном

- **WHEN** запрошен тайл целиком над океаном
- **THEN** ответ `404`, клиент показывает отсутствие высоты

### Requirement: Сжатие, кеш и CORS

Ответ SHALL отдаваться с `Content-Encoding: gzip`, `Access-Control-Allow-Origin: *` и кешированием не меньше суток.

#### Scenario: Заголовки ответа

- **WHEN** клиент запрашивает существующий тайл
- **THEN** в ответе есть `Content-Encoding: gzip`, `Access-Control-Allow-Origin: *` и `Cache-Control` с `max-age` не меньше 86400
