# Design

## Context

Мотивация — в `proposal.md`. Клиент: `src/lib/leaflet.layer.elevation-display/index.js` (`maxNativeZoom: 11`, `noDataValue: -512`, `decodeElevations` — префиксная сумма Int16; `404` — нет данных). Тайлы автора проверены 2026-10-07: 131 072 байта после распаковки, `Content-Encoding: gzip`, `Access-Control-Allow-Origin: *`, `Cache-Control: max-age=86400`, `404` на z12. Данные — перепакованные куски DEM 3″ viewfinderpanoramas из `add-elevation-api` (README генератора тайлов автора `wladich/elevation_tiles_for_nakarte` предлагает их же).

## Goals / Non-Goals

**Goals:**
- Формат автора без правок клиента.
- Без миллионов объектов в R2.

**Non-Goals:**
- Терраин-тайлы в форматах terrarium или Terrain-RGB.
- Отмывка рельефа (hillshade).

## Decisions

### Вся пирамида офлайн в один PMTiles

Генерация на лету не годится для нижних зумов: тайл z8 покрывает ~1.4° и задевает сотни кусков, z0 — весь мир. Поэтому генератор строит все тайлы z0–11 офлайн и пишет один архив PMTiles (тайлы внутри уже сжаты gzip); тайлы без данных в архив не попадают. Worker читает тайл range-запросом к архиву в R2 по директории PMTiles и отдаёт тело как есть с `Content-Encoding: gzip`.

Альтернативы: отдельные объекты в R2 — до 5.6 млн записей (≈ $21 только за запись); генерация z8–11 на лету и архив только для z0–7 — две схемы вместо одной без выигрыша.

### Значение пикселя через ядро сервиса высот

Генератор использует интерполяцию из `core` (`add-elevation-api`), чтобы тайлы и API давали одни и те же высоты; для нижних зумов значение берётся в центре пикселя без усреднения, как требует спека.

### Маршрут

Тайлы отдаёт тот же Worker сервиса высот по префиксу (например, `/tiles/{z}/{x}/{y}`): данные и деплой общие. Если лимиты Worker будут мешать, маршрут выносится в отдельный Worker без изменения формата.

## Risks / Trade-offs

- [Размер архива и время генерации] → прогон вне CI; сначала регион, затем весь мир; размер и время записать в этот файл.
- [Значения на нижних зумах — точечная выборка, не среднее] → совпадает с ожиданием клиента (он читает одно значение на пиксель), спека фиксирует центр пикселя.

## Migration Plan

Генерация архива → загрузка в R2 → маршрут в Worker → `elevationTileUrl` в `config-target/clone.js`. Откат — вернуть URL автора.
