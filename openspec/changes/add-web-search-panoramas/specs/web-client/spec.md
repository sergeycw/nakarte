# Spec Delta

## ADDED Requirements

### Requirement: Открыть место на другой карте

Кнопка внешних карт SHALL открывать меню `Open this place in` с пунктами Google, Yandex, OpenStreetMap, Google Earth 3D, Mapy.com, Wikimapia, Meteoblue. Пункт SHALL открывать в новой вкладке адрес сервиса с центром и масштабом текущего вида (зум старого клиента в пределах, которые понимает сервис). Высота камеры Google Earth SHALL учитывать высоту места из API высот, без ответа — 8000 м.

#### Scenario: Открыть в OpenStreetMap

- **WHEN** карта показывает 41.69, 44.78 с масштабом зума 14 старого клиента, и пользователь выбирает OpenStreetMap
- **THEN** открывается новая вкладка `https://www.openstreetmap.org/#map=14/41.69…/44.78…`

#### Scenario: Зум за пределами сервиса

- **WHEN** масштаб зума 21 старого клиента, и пользователь выбирает OpenStreetMap
- **THEN** в адресе зум 19

### Requirement: Где я

Кнопка геолокации SHALL запрашивать положение у браузера, показывать на карте точку с кругом точности, переводить к ней карту и следовать за положением, пока пользователь не сдвинет карту; повторное нажатие возвращает к положению, следующее — выключает. Ошибка запроса SHALL давать тост: `Geolocation is blocked for this site. Please, enable in browser setting.`, `Failed to acquire position for unknown reason.` или `Geolocation error: <текст>`.

#### Scenario: Положение получено

- **WHEN** браузер разрешил геолокацию, и пользователь нажимает кнопку
- **THEN** на карте точка положения с кругом точности, карта переходит к ней

#### Scenario: Геолокация запрещена

- **WHEN** пользователь нажимает кнопку, а браузер отказал в доступе
- **THEN** появляется тост `Geolocation is blocked for this site. Please, enable in browser setting.`

### Requirement: Геолокация недоступна

Если в браузере нет геолокации или доступ к ней для сайта уже запрещён, кнопка геолокации SHALL быть неактивной с подсказкой `Location not available`.

#### Scenario: Доступ запрещён раньше

- **WHEN** доступ к геолокации для сайта уже запрещён, и пользователь открывает приложение
- **THEN** кнопка геолокации неактивна, при наведении — `Location not available`

### Requirement: Последнее положение при заходе

Новое приложение SHALL запоминать последнее полученное положение пользователя. При заходе без вида в адресе и без треков в адресе приложение SHALL открываться на запомненном положении с зумом по умолчанию и, если оно есть, коротко запрашивать текущее положение без подсказки разрешения. Отказ в доступе SHALL стирать запомненное положение.

#### Scenario: Заход с запомненным положением

- **WHEN** положение 41.69, 44.78 запомнено, и пользователь открывает приложение без параметров
- **THEN** карта открывается с центром 41.69, 44.78

#### Scenario: Заход по ссылке с видом

- **WHEN** положение запомнено, а адрес содержит `m=`
- **THEN** карта открывается на виде из адреса

### Requirement: Масштаб и зум на карте

Новое приложение SHALL показывать линейку масштаба в метрах и километрах и номер текущего зума в единицах старого клиента рядом с кнопками зума.

#### Scenario: Номер зума

- **WHEN** приложение открыто по адресу `#m=13/42.68490/47.07008`
- **THEN** рядом с кнопками зума номер `13`, внизу карты линейка масштаба
