# Proposal

## Why

Новое приложение на `/next/` прокладывает и правит треки и показывает профиль высот, но в нём нельзя найти место по названию, координатам или ссылке, посмотреть Street View, открыть это место на другой карте, найти себя на карте и измерить расстояние — а старый клиент всё это умеет. Без этих функций переключение на новое приложение (change 9) отнимает их у пользователя. Это change 8, последний перед переключением, из [списка ресёрча](../../research/new-ui.md#changes-по-порядку).

## What Changes

- Поиск: строка поиска в панели с названием. По названиям — mapy.cz через CORS-прокси клона, как у старого клиента; при ошибке mapy.cz — photon.komoot.io напрямую. Координаты в любом формате старого клиента и ссылки на карты (Google, Яндекс, OSM, mapy.com, nakarte, короткие ссылки Google и mapy.com через прокси) разбираются без поисковика. Выбор результата переводит карту и ставит метку.
- Метка найденного места с названием; её положение и название живут в адресе (`r=lat/lng/название`, как у старого клиента) и не попадают в «Copy link». Клик по метке при постановке точки трека или рисовании линии ставит точку туда (с названием метки для точки трека).
- Street View: кнопка включает режим — слой покрытия Google поверх слоёв, клик по карте ищет ближайшую панораму, панорама открывается в нижней панели, на карте — метка с направлением взгляда. Состояние — в адресе `n2=` (и старый `n=`), как у старого клиента. Maps JavaScript API грузится только при первом поиске панорамы; ключ — из того же секрета `GOOGLE_MAPS_API_KEY` переменной сборки `VITE_GOOGLE_MAPS_API_KEY`, без него — режим без ключа со скрытием режима разработки, как у старого клиента.
- Внешние карты: меню «Open this place in» — Google, Yandex, OpenStreetMap, Google Earth 3D, Mapy.com, Wikimapia, Meteoblue (все адреса проверены живыми).
- Геолокация: кнопка «Где я» со следованием за положением и точностью, понятные сообщения об ошибке (нет поддержки, запрещено, не удалось); при заходе без вида в адресе — последнее известное положение, как у старого клиента.
- Линейка шкалы и номер зума у кнопок зума.
- Линейка «Measure distance»: новый трек «Ruler» с отметками расстояния и сразу рисование. Отметки расстояния — у любого трека пунктом меню трека; флаг `measureTicksShown` уже читается и пишется в ссылках и автосохранении.
- Тесты без сети: unit — координаты, ссылки, ответы mapy.cz и photon на фикстурах, адрес `r=` и `n2=`, отметки расстояния, адреса внешних карт; browser mode — в `App` с заглушками `fetch`, Street View и геолокации; e2e — поиск, метка, Street View с заглушкой Maps JavaScript API и покрытия, линейка.
- Не входит: старый клиент, `q=` (запрос поиска в адресе старого клиента — новое приложение его не пишет), провайдеры панорам кроме Google, свой ключ Google (заводит владелец), короткие ссылки `maps.app.goo.gl` (не проверены на живой ссылке — backlog), полировка вида (change `polish-web-ui`).

## Capabilities

### New Capabilities

- `map-search`: поиск места по названию, координатам и ссылкам на карты, метка найденного места и её параметр `r=` в адресе.
- `street-view`: режим Street View нового приложения — покрытие, поиск панорамы по клику, панель панорамы, метка направления на карте, параметры `n2=` и `n=`, загрузка Maps JavaScript API и ключ.

### Modified Capabilities

- `web-client`: новые требования — «Открыть место на другой карте», «Где я», «Геолокация недоступна», «Последнее положение при заходе», «Масштаб и зум на карте».
- `tracks`: новые требования — «Отметки расстояния» и «Линейка».
- `clone-deploy`: новое требование — ключ Google для нового приложения из того же секрета.

## Impact

- Новый код: `web/src/search/` (провайдеры, разбор координат и ссылок, панель поиска, метка), `web/src/streetview/` (загрузка API, покрытие, панель, метка направления), `web/src/map/` (внешние карты, геолокация, кнопки карты), `web/src/tracks/ticks.ts` (отметки расстояния).
- Изменения: `web/src/state/store.ts` и `sync.ts` (`r=`, `n2=`, `n=`), `App.tsx` (`--bottom-inset` с двумя нижними панелями, пропы заглушек), `map/BaseMap.tsx`, `layers/style.ts`, `tracks/TrackList.tsx` и `tracks/style.ts`, `routing/MapEditor.tsx` (клик по карте в режиме Street View), `InfoPanel.tsx`, `config.ts`, тестовые помощники и e2e-фикстура сети; `.github/workflows/deploy-pages.yml` (ключ в шаг сборки `web/`); `AGENTS.md`, `openspec/backlog.md`.
- Внешние сервисы: mapy.cz suggest через существующий прокси (роли прокси не меняются), photon.komoot.io напрямую (CORS `*`), Google Maps JavaScript API и тайлы покрытия (CORS `*`), сервис высот — для Google Earth. С dev-сервера (8769) и `vite preview` (4173) прокси и сервис высот недоступны: живая проверка — на проде после деплоя.
- Новые секреты не нужны: секрет `GOOGLE_MAPS_API_KEY` уже предусмотрен для старого клиента (сейчас не заведён).
