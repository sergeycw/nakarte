## MODIFIED Requirements

### Requirement: Список треков поверх карты

Новое приложение SHALL показывать поверх карты список треков: у каждого трека — флажок видимости, цвет, название и длина всех его отрезков в километрах (два знака до 10 км, один — до 100 км, без дробной части дальше, как в старом клиенте). Клик по названию SHALL показывать трек целиком. Список SHALL открываться кнопкой `Tracks` с числом треков и закрываться ею же или кликом по карте, чтобы не закрывать карту.

#### Scenario: Трек в списке

- **WHEN** открыт трек из двух отрезков общей длиной 12 345 м
- **THEN** в списке есть строка с его названием, цветом, отмеченным флажком и длиной `12.3 km`

#### Scenario: Показать трек целиком

- **WHEN** пользователь кликает по названию трека, который не виден на карте
- **THEN** карта переходит так, что трек виден целиком

#### Scenario: Список по кнопке

- **WHEN** у пользователя три трека, список закрыт, и он нажимает кнопку `Tracks 3`
- **THEN** список открывается; клик по карте его закрывает, треки остаются на карте

## ADDED Requirements

### Requirement: Кнопка профиля высот

Внизу карты SHALL быть кнопка `Elevation profile` с длиной текущего трека: редактируемого, иначе того, чей профиль открыт, иначе первого видимого трека с линиями. Пока профиль этого трека посчитан, рядом с длиной SHALL стоять подъём. Кнопка SHALL открывать профиль высот этого трека и закрывать открытый. Без такого трека кнопки нет.

#### Scenario: Открыть профиль кнопкой

- **WHEN** видим трек длиной 8.01 km, и пользователь нажимает `Elevation profile`
- **THEN** снизу открывается профиль этого трека, кнопка показывает `8.01 km` и подъём; повторное нажатие профиль закрывает

#### Scenario: Нет треков с линиями

- **WHEN** треков нет или у видимых треков только точки
- **THEN** кнопки `Elevation profile` нет
