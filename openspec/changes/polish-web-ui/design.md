# Design

## Context

Зачем — [proposal](proposal.md), поведение — [дельта `web-client`](specs/web-client/spec.md). Выбор библиотеки и темы — [ресёрч, п. 2](../../research/new-ui.md#2-ui-библиотека) и архивы [record-ui-decisions](../archive/2026-10-08-record-ui-decisions/design.md), [record-new-ui-decisions](../archive/2026-10-08-record-new-ui-decisions/design.md): shadcn/ui на Base UI, Tailwind 4, только светлая тема, интерфейс только на английском, телефон — полноценная цель.

Что есть сейчас (`master` `990de65`):

- Тема — `web/src/index.css`: пресет `base-nova` shadcn 4.21 (`components.json`), палитра `neutral` в `oklch` без цветового акцента (`--primary` почти чёрный), `--radius: 0.625rem`, шрифт Geist пакетом `@fontsource-variable/geist`. Блока `.dark` нет, `@custom-variant dark` держит классы `dark:` под несуществующим классом ([add-web-skeleton](../archive/2026-10-08-add-web-skeleton/design.md#панель-и-тост)). Иконки — `lucide-react`.
- Компоненты `web/src/components/ui/`: `button`, `card`, `checkbox`, `dialog`, `dropdown-menu`, `input`, `popover`, `radio-group`, `toast`.
- Раскладка: левая колонка `w-80` — `InfoPanel` (название, GitHub, строка поиска) и `TrackList`; справа сверху — кнопка слоёв (`LayerSwitcher`, поповер), под ней контролы MapLibre (зум, номер зума, геолокация) и своя группа (Street View, линейка; меню внешних карт удалено в change [remove-external-maps](../archive/2026-10-09-remove-external-maps/proposal.md)) — `MapButtons.tsx`; снизу на всю ширину — профиль высот (`12rem`) и панорама над ним; панели редактора и точек — плашка снизу по центру над нижними панелями (`--bottom-inset`); тосты справа снизу (на телефоне — по центру) над ними же; меню на карте — `DropdownMenu` с якорем в точке клика; диалоги — `Dialog`. Атрибуция и масштаб MapLibre — над `--bottom-inset`.
- Ограничения вёрстки — `AGENTS.md`, раздел «Приложение»: `isolation: isolate` у контейнера карты, CSS MapLibre вне `@layer` (свойства `.maplibregl-ctrl-*` — с `!`), `--bottom-inset` и `--profile-inset` на `<html>`.

Отложенное в этот change из прошлых: вид панелей редактора, профиля, меню и маркеров ([add-web-route-editor](../archive/2026-10-09-add-web-route-editor/design.md), [add-web-line-tools](../archive/2026-10-09-add-web-line-tools/design.md), [add-web-elevation-profile](../archive/2026-10-09-add-web-elevation-profile/design.md), [add-web-search-panoramas](../archive/2026-10-09-add-web-search-panoramas/design.md#risks--trade-offs)); тост поверх панели редактора на узком окне; столбец кнопок справа под панелью панорамы в низком окне; две нижние панели на телефоне оставляют ≈ 330 px карты; неактивная кнопка геолокации без объяснения на телефоне; подсветка трека при наведении, начало и конец трека цветом, «Show all / Hide all» ([add-web-tracks](../archive/2026-10-08-add-web-tracks/design.md)), подсказка отрезка с длиной, перетаскиваемая граница панорамы.

## Goals / Non-Goals

**Goals:**
- Промпт для Claude Design, по которому можно сделать раскладку без доступа к коду: экраны, компоненты, тема, ограничения, что нельзя менять, скриншоты всех экранов на компьютере и Pixel 7.
- Правки по ответу — в теме и вёрстке, без смены поведения, кроме дельты спеки.

**Non-Goals:**
- Тёмная тема, перевод интерфейса, другая UI-библиотека — решения владельца.
- Новое поведение из отложенного (подсветка при наведении, подсказка отрезка, «Show all / Hide all», граница панорамы) — backlog, если Claude Design не сделает его частью раскладки.
- Вид карты (подложка, стиль слоёв) — change 10 и backlog.

## Decisions

Решения, которых нет в ресёрче, архивах и задаче change, помечены **[агент]**.

### Два этапа и стоп между ними

Задача владельца: агент собирает промпт и скриншоты, отдаёт их владельцу и ждёт ответа Claude Design; вёрстку до ответа не трогает. Причина — главный принцип UI владельца («красиво, просто, понятно») агент сам не выверит, а правки вёрстки без согласованного макета дали бы ещё один круг. Артефакты change (proposal, дельта, design, tasks) пишутся до стопа; дельта спеки — минимальная, по отложенным дефектам, и дополняется после ответа, если правка вёрстки задевает сценарий.

Промпт и скриншоты лежат вне репозитория (скрэтчпад сессии) и отдаются владельцу файлами: в репозитории они устарели бы с первой правкой. В design после ответа записывается, что предложил Claude Design и что из этого взято.

### Скриншоты: `vite preview` и подмена сети **[агент]**

Стенд — headless Playwright из `web/node_modules/playwright`, скрипт вне репозитория, сборка клона (`npm run build`) под `vite preview` на 4173; компьютер — 1280×800, телефон — профиль `Pixel 7` Playwright (412×839, DPR 2.625, touch). Каждый кадр — новый контекст браузера (своя IndexedDB): с сохранённым списком повтор ссылки даёт дубль трека.

- Подложка — `l=O`: ключа Tracestrack на 2026-10-09 нет (прокси отвечает `503` на тайл `Tt`), и без него в каждом кадре был бы тост отката. Тайлы OSM — настоящие (несколько десятков на кадр, в пределах политики OSMF); вид с Tracestrack — после ключа владельца.
- Поиск, сервис высот, хранилище треков — `context.route` с фикстурами e2e (`src/search/fixtures/`, высота — функция широты, как `elevationAt` в `e2e/fixtures.ts`).
- Прокладка — заглушка CheerpJ в скрипте воркера, как в e2e, только `WasmRouter.route` пересылает запрос локальному серверному BRouter (`docker start nakarte-brouter`, тайлы `E40_N40` в `brouter/segments4/`): запрос движка и сервера — одна строка (`routing/brouter.ts`), а настоящий маршрут по тропам в кадре понятнее прямой с изломом из заглушки e2e. Контейнер после кадров останавливается.
- Street View — заглушка Maps JavaScript API из e2e с картинкой в окне: настоящие снимки Google локально отвечают `429` (`AGENTS.md`), а для макета важна рамка панели, а не снимок. Тайлы покрытия — настоящие (`maps.googleapis.com/maps/vt`, без ключа).

Выяснилось при съёмке: воркер движка на `localhost:4173` не достаёт BRouter на `localhost:17777` (`Failed to fetch` в тосте прокладки), поэтому заглушка зовёт `/__brouter` того же origin, а `context.route` пересылает запрос в BRouter из Node. Название трека из файла — имя файла с расширением (`Narikala.gpx`), как у старого клиента.

### Канал к Claude Design

Промпт — текстом в чат и файлом, скриншоты — файлами (`SendUserFile`): 52 кадра, 26 экранов × компьютер и `Pixel 7`, 2026-10-09; PNG-архив (62 МБ) не проходит лимит 30 МБ для телефона владельца, поэтому вторым архивом — JPEG (14 МБ). Промпт — на английском (интерфейс английский, Claude Design получает его как есть); в репозиторий не кладётся. В сессии доступен Artifact типа Design (`quickstart`, intent `design`) — холст с артбордами, который агент может заполнить сам. Какой путь брать, решает владелец (вопрос в сессии); ответ — сюда.

### Что Claude Design менять нельзя

Поведение и сценарии спек, тексты UI (по ним ищут тесты: `getByRole` с `exact: true`, `getByText`), `data-testid` и `aria-label`, раскладку кнопок карты как контролов MapLibre (столбец справа), структуру нижних панелей через `--bottom-inset`/`--profile-inset`, светлую тему без `.dark`, шрифт без внешних запросов (сборка не ходит в сеть, `check-no-author-hosts`). Новые компоненты shadcn — можно (`shadcn add`, правило `optimizeDeps.include` для browser-тестов).

### Дефекты раскладки — в этом change **[агент]**

Три отложенных дефекта (кнопки под панелью в низком окне, тост поверх панели редактора, неактивная геолокация на телефоне) — часть «полировки», и исправлять их отдельно от новой раскладки значило бы править те же места дважды. Как именно — по ответу Claude Design; требования — дельта спеки. Неактивную кнопку `GeolocateControl` MapLibre делает `disabled`, и клик до неё не доходит: слушатель на контейнере контрола (`pointerup` по области кнопки) — деталь apply.

### Тесты

Сценарии дельты — browser-тесты (`App.browser.test.tsx`: окно 844×390 через `page.viewport`, тост при панели редактора; неактивная геолокация через подмену `navigator.permissions`) и e2e на `Pixel 7` для касаний. Существующие тесты не переписываются под новые тексты: тексты не меняются. Визуальных снимков в CI нет **[агент]**: рендер карты в headless Chromium (SwiftShader) нестабилен по пикселям, а тайлы — фикстура; вид проверяется скриншотами владельцу.

### Цикл change быстрее **[владелец]**

Решение владельца 2026-10-09 в этой сессии (вопрос «почему упала скорость»; замер: e2e ≈ 72 с локально, `check web` ≈ 5.5 мин, `deploy pages` ≈ 4 мин, archive-PR ≈ 10 мин на change): во время работы — только затронутые тесты, полный `npm test` и e2e — один раз перед PR; archive — в том же PR, что change, проверки прода после деплоя записываются в следующий change; промпт следующей сессии велит читать только архивы и спеки, которые change трогает. Тесты в `deploy pages` остаются: его e2e проверяет сборку с ключом Google.

### Внешние карты удалены **[владелец]**

По скриншоту меню «Open this place in» владелец назвал функцию лишней: удалена отдельным change [remove-external-maps](../archive/2026-10-09-remove-external-maps/proposal.md) (PR sergeycw/nakarte#123), чтобы не ждать ответа Claude Design. Скриншоты сняты уже без неё.

## Risks / Trade-offs

- [Ответ Claude Design опирается на скриншоты без кода и может предложить невозможное в MapLibre (кнопки вне столбца контролов, свои `z-index` поверх карты)] → ограничения в промпте; что не ложится, записывается сюда с причиной.
- [Скриншоты на OSM, а прод по умолчанию на Tracestrack] → после ключа владельца — кадры с Tracestrack; палитра интерфейса не должна спорить с яркой туристической подложкой — сказано в промпте.
- [Правка `components/ui` расходится с обновлениями shadcn через CLI] → правки темы — переменными в `index.css`, компонентов — минимальные; список правленых файлов — в design после apply.
- [Решения **[агент]** без подтверждения] → вынесены в заголовки, правка — мелкий change.

## Migration Plan

1. Этап 1: промпт и скриншоты владельцу; стоп до ответа Claude Design.
2. Этап 2: правки по ответу, тесты, ревью диффа субагентом, PR в `master`, все проверки `pass` на последнем коммите, merge, деплой; скриншоты прода владельцу.
3. Archive в том же PR (решение владельца выше); ресёрч удаляется, если все его changes сделаны (`AGENTS.md`, «Где что записано»), причины решений уже в архивах.
4. Откат — revert и push: форматы ссылок и автосохранения не меняются.
