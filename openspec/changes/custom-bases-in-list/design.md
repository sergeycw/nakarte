# Design

## Context

`All layers` (`LayerSwitcher.tsx`) показывает подложки списка радиокнопками (`RadioGroup`, всегда раскрыты, архив `compact-all-layers`), под ними — секции оверлеев, среди них хитмэпы Strava. Подложки каталога с `quick-layer-menus` есть в кругах столбца и их меню, хитмэпы — в кнопке хитмэпа и её меню (`QuickLayers.tsx`, группы `quick-layers.ts`), снимки по датам — кнопкой `QuickDated`. Свои слои (`custom.ts`, коды `-cs…`) ни в одну группу не входят. Галочки Configure layers (`isListed`, `settings.ts`) по умолчанию — `isDefault` каталога; диалог по Ok сохраняет состояние всех галочек разом. Почему меняем — proposal, «Why».

## Goals / Non-Goals

**Goals:**
- Каждая подложка и каждый хитмэп выбираются в одном месте интерфейса.
- Галочка Configure layers у слоя группы честно показывает, есть ли он в меню.

**Non-Goals:**
- Секции остальных оверлеев, `Add custom layer` и правка своего слоя не меняются.
- Состав групп и поведение кругов и меню не меняются.

## Decisions

### В списке — только свои подложки (владелец)

Варианты из опроса 2026-10-29: только свои подложки, свои и снимки по датам (снимки тогда в двух местах), или убрать раздел совсем (своим подложкам нужно другое место, например пункт в меню круга, а типа у них нет). Владелец выбрал первый. Фильтр — `isCustomLayerCode` поверх прежнего отбора строк списка (`isListed` или выбранная): своя подложка, скрытая в Configure layers, пропадает и из списка, как раньше.

Раздел подложек без строк не рисуется. Первая секция оверлеев тогда стоит вверху панели, и её верхняя линия-разделитель лишняя: `first:border-t-0 first:pt-0` у секции.

### Хитмэпы — только в кнопке (владелец)

Варианты из опроса: убрать все четыре хитмэпа из `All layers`, как подложки, или показывать их и в кнопке, и в секции `Overlays` (три новые строки-дубля). Владелец выбрал первый: каждый слой — в одном месте. Секции оверлеев строятся без слоёв групп столбца (`quickGroupOf`). Кнопка хитмэпа теперь есть всегда, как круги: другого места у хитмэпов нет. Прежнее правило «кнопка — только при `Sa` в списке» снято.

### Галочки слоёв групп по умолчанию стоят (агент)

Владелец решил оставить подложки в Configure layers: их галочки управляют меню кругов. Но у `Otm`, `Oso`, `Ocm`, `Sr`, `Sb` и `Sw` нет `isDefault`: в диалоге они без галочки, а в меню — есть (решение агента в `quick-layer-menus`: меню прячет только снятые пользователем). Диалог по Ok пишет состояние всех галочек, и после любого Ok эти слои становились «снятыми» и пропадали из меню. Так ловил browser-тест «Скрыть слой из списка».

Поэтому умолчание галочки — `listedByDefault` в `settings.ts`: свой слой, слой группы столбца или `isDefault` каталога. Галочка слоя группы — его место в меню, и снять её — убрать слой из меню. Reset в диалоге даёт то же умолчание. Меню снова фильтрует по `isListed`. Для `All layers` это ничего не меняет: слоёв групп там нет.

Отвергнуто: писать по Ok только изменённые галочки (диалог показывал бы слой в меню без галочки, а скрыть его было бы нельзя) и `isDefault: true` у этих слоёв в каталоге (каталог — данные старого клиента, а умолчание тут — свойство меню).

### Старые настройки — без прежних умолчаний (агент)

Настройки версии 1 и `leafletLayersSettings` старого клиента писали галочки всех слоёв. В них `false` у слоя группы без `isDefault` — прежнее умолчание, а не выбор: меню появились только в `quick-layer-menus`. Без поправки у тех, кто хоть раз нажимал Ok в Configure layers (и у пользователей старого клиента), OpenTopoMap и хитмэпы run, ride, winter пропали бы из меню. `loadSettings` отбрасывает такие записи у версии 1 и старого клиента, настройки пишутся версией 2, где `false` — выбор пользователя. Цена: снятая в последние часы до выката галочка такого слоя (версия 1 после `quick-layer-menus`) вернётся. Это редкий случай, и галочку можно снять снова.

### Кнопки с меню — сверху столбца (владелец)

Владелец 2026-10-29: «чтобы все кнопки со стрелками были вверху». Порядок столбца: три круга, кнопка хитмэпа, кнопка снимков по датам (`LayerSwitcher.tsx`, порядок монтирования). Снимки по датам по-прежнему под кругами, теперь — под кнопкой хитмэпа.

### Configure layers без изменений (владелец)

Варианты: оставить галочки подложек каталога (они управляют меню кругов) или убрать подложки из Configure layers (меню всегда показывает всю группу). Владелец выбрал первый. Сценарий «Скрыть слой из списка» теперь проверяет меню топокарты: CyclOSM пропадает из него и остаётся скрытым после перезагрузки.

### Свой адрес при старте — по-прежнему не ссылка

Сценарий «Слой из меню после перезагрузки» (`quick-layer-menus`) проверял, что `All layers` не получает слой из меню. Слоёв групп там больше нет, а галочки слоёв групп и так стоят, поэтому сценарий теперь проверяет другое следствие того же решения: снятая галочка слоя, который на карте, переживает перезагрузку со своим `l=`.

## Risks / Trade-offs

- [Пользователь привык выбирать подложку и хитмэп в `All layers`] → круги и кнопка хитмэпа стоят прямо над `All layers`, каждый слой есть в меню своей кнопки.
- [Миграция возвращает галочки, снятые после выката `quick-layer-menus` и до этого change] → окно в несколько часов, галочку можно снять снова.
- [Тесты вида не пишутся (backlog, «Интерфейс после макета 4a»)] → состав списка, порядок столбца и галочки проверяют unit- и browser-тесты; вид — скриншотами.
