# Design

## Context

Шаги владельца из `openspec/research/security-audit.md`: деплойный токен `nakarte deploy` сужен до Editor на четыре Worker'а и Pages Write. Синхронизация (`scripts/brouter-tiles-sync.mjs`) звала `npx wrangler r2 object get/put --remote`, это REST API `…/r2/buckets/{bucket}/objects/{key}`; с правом на один бакет оно отвечает `403` (прогон `brouter tiles sync` 2026-10-08, 13:06 UTC). Заливка высот (`workers/elevation/scripts/elevation-data.sh`) с самого начала ходит в S3 API R2 через `aws` CLI с ключами токена «nakarte-elevation data upload», и S3 API право на бакет принимает.

## Goals / Non-Goals

**Goals:** синхронизация работает без права R2 на весь аккаунт; сбой чтения манифеста не стирает версии тайлов.

**Non-Goals:** тесты синхронизации в CI — скрипт ходит в brouter.de и R2, без сети его проверяет только ручной прогон (так было и до change'а); версии в ключах тайлов (аудит системного дизайна, P2).

## Decisions

- **S3 API через `aws` CLI.** Он есть на раннерах `ubuntu-latest`, его уже использует заливка высот; сам делает multipart для тайлов до 253 МБ. Альтернатива — подпись SigV4 в Node без зависимостей — больше кода ради того же. Ключи очищаются от пробелов и переводов строки, как в `elevation-data.sh`: после копирования из дашборда секрет часто приходит с `\n`, и `aws` собирает битый `Authorization`.
- **Те же ключи, что у высот.** Токен «nakarte-elevation data upload» получил `nakarte-tiles` в том же праве Bucket Item Write; значения ключей не меняются, секреты GitHub не трогаются. Цена — один ключ пишет в два бакета; оба восстанавливаются workflow, треки он не видит. Отдельный токен потребовал бы ручного переноса значений в новые секреты.
- **`wrangler --local` для локального режима.** Локальный R2 — это `wrangler dev`, S3 API у него нет.
- **Пустой манифест — только на `NoSuchKey`.** В удалённом режиме `aws s3api get-object` на отсутствующий ключ пишет в stderr `NoSuchKey`; всё остальное (права, сеть, endpoint) — ошибка прогона. В локальном режиме поведение прежнее: любой сбой — пустой манифест, это стенд разработчика.

## Risks / Trade-offs

- [`aws` CLI нет у разработчика] → локально нужен только `wrangler`; удалённый режим запускает workflow.
- [Ключи R2 утекут] → запись мусора в два бакета вместо одного; оба восстанавливаются, треки недоступны.
