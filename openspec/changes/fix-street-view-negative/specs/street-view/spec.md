## MODIFIED Requirements

### Requirement: Ключ Google в новом приложении

Новое приложение SHALL загружать Maps JavaScript API с ключом из переменной сборки `VITE_GOOGLE_MAPS_API_KEY`, а без неё — с пустым ключом. С пустым ключом панель панорамы SHALL показывать панораму в нормальных цветах без водяного знака и окна режима разработки Google, как старый клиент (capability `clone-hosting`, «Street View без ключа без режима разработки»); с ключом — как её рисует Google.

#### Scenario: Сборка без ключа

- **WHEN** приложение собрано без `VITE_GOOGLE_MAPS_API_KEY`
- **THEN** Maps JavaScript API запрашивается с пустым `key=`, правила режима без ключа применяются к панели панорамы

#### Scenario: Сборка с ключом

- **WHEN** приложение собрано с `VITE_GOOGLE_MAPS_API_KEY`
- **THEN** Maps JavaScript API запрашивается с этим ключом, правила режима без ключа не применяются

#### Scenario: Google не инвертировал панораму

- **WHEN** приложение собрано без ключа, а Google показал панораму без своей инверсии
- **THEN** панорама в нормальных цветах, а не в негативе
