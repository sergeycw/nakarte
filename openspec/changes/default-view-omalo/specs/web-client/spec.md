## MODIFIED Requirements

### Requirement: Полноэкранная карта

Приложение SHALL занимать картой всё окно браузера без прокрутки страницы и SHALL показывать подложку по умолчанию (Tracestrack Topo, capability `map-layers`) с её атрибуцией, если в адресе и в сохранённом выборе нет другого слоя. Начальный вид без годного `m=` в адресе SHALL показывать село Омало в Тушети: центр 42.37889, 45.63000, `m=13` (тайлы z13).

#### Scenario: Первый заход

- **WHEN** пользователь открывает `/` без параметров
- **THEN** карта заполняет окно, показаны тайлы Tracestrack Topo z13 вокруг 42.37889, 45.63000 (Омало) и подпись «Maps © Tracestrack»

#### Scenario: Окно телефона

- **WHEN** приложение открыто в окне 390×844
- **THEN** карта заполняет окно, у страницы нет горизонтальной и вертикальной прокрутки
