## ADDED Requirements

### Requirement: Секреты только у шагов публикации

В workflow деплоя секреты Cloudflare SHALL передаваться только шагам, которые зовут `wrangler`, а `wrangler` SHALL запускаться точной версией. Установка зависимостей, тесты и сборка SHALL идти без секретов. Действия GitHub в своих workflow SHALL закрепляться полным SHA коммита.

#### Scenario: Пакет со скриптом установки

- **WHEN** зависимость клиента при `yarnpkg` читает окружение процесса
- **THEN** `CLOUDFLARE_API_TOKEN` в нём нет

#### Scenario: Перезаписанный тег действия

- **WHEN** автор действия перенёс тег `v2` на другой коммит
- **THEN** workflow исполняет коммит, закреплённый в файле
