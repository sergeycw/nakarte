# Design

## Context

Вопросы — аудит системного дизайна, «Оценка сейчас и вопросы владельцу». Ответы владелец дал в сессии 2026-10-08, вместе со скриншотами удаляемых функций. Ниже — ответы в его формулировке и что из них следует; где ответа нет, это сказано.

## Decisions

### Браузеры: только последние версии

Новый UI работает только в последних версиях браузеров. Firefox 52 ESR из матрицы karma апстримного `check` (`main.yml`) уходит вместе со старым клиентом; современный синтаксис и API без полифиллов.

### Главный принцип UI: красивый, простой и понятный

Упор нового UI — красивый, простой и понятный интерфейс. Только светлая тема, тёмной не будет. Растровые тайлы (как сейчас, Leaflet) или векторные со своим стилем (MapLibre) — владелец вопроса не понял, решение передано ресёрчу нового UI с этим принципом как критерием.

### Сервер роутинга на VPS: только если общий счёт заметно не вырастет

VPS с серверным BRouter вместо CheerpJ в браузере рассматривать можно, но если он добавляет ≈ $5 к нынешним ≈ $5.25 в месяц (счёт вдвое, ≈ $10), владелец этого не хочет. По умолчанию движок остаётся в браузере (CheerpJ); ресёрч считает цену VPS и сравнивает с этим порогом.

### Ошибка прокладки: отрезок помечается непроложенным

Вместо незаметного прямого отрезка (спека `routing`, «Ошибка прокладки даёт прямой отрезок») отрезок, который не удалось проложить, помечается как непроложенный, а ошибка показывается уведомлением-тостом. Требование меняется в change нового редактора.

### Совместимость ссылок с nakarte.me автора не нужна

Ссылки нового UI могут нести разметку маршрута (новая версия `nktk` или новый параметр), а не только геометрию (спека `route-editing`, «Ссылки и экспорт несут только геометрию»). Читать старые ссылки клона (`nktl=`, `nktk=` всех версий, коды слоёв `l=`) новый UI по-прежнему обязан — это требование «Старые коды удалённых слоёв» и контракты из аудита, п. 2; владелец их не отменял.

### Удаляемые функции

В новом UI их нет (скриншоты владельца 2026-10-08):

- экспорт Garmin JNX;
- печать в PDF: страницы, масштаб печати, магнитные меридианы, километровая сетка, настройки бумаги и dpi;
- контрол координат под курсором с выбором формата (`±ddd.ddddd`, `ddd°mm.mmm′` и др.) и галочкой «Display elevation» — высотой под курсором;
- меню «Recent sessions» и «Copy share link»;
- инструмент азимута: истинный и магнитный азимут, расстояние, «Reverse», «Elevation / Sightline».

Следствия, которые решает ресёрч нового UI, а не этот change:

- Высоту под курсором показывали тайлы высот (`elevation-tiles`); других клиентов у них в коде нет. Без этой функции тайлы высот z0–11 и архив в R2 (≈ 3.8 ГБ) остаются без потребителя: оставить под другую функцию или вывести из эксплуатации.
- Без печати через прокси перестают идти растеризованные для PDF слои с `noCors` (`slazav.xyz`, свои слои пользователя); показ слоёв с `noCors` и обрезкой по контуру (`static.mapy.hiking.sk`, `TileLayer.cutline`), слои Strava, swisstopo, Tsvetkov, Wikimapia, импорт и поиск остаются.
- «Recent sessions» — это список сессий; сохранение разметки маршрута между перезагрузками (спека `route-editing`) на сессиях и держится. Убирается ли только список или и восстановление — уточнить у владельца.
- «Copy share link» — ссылка на вид карты; копирование ссылки на треки (`nktl=`) — другая функция, владелец её не называл.

### Стек

Пожелание владельца: последние React, Vite, Vitest и Biome — быстрый, простой, понятный современный стек, который легко поддерживать; подтверждается ресёрчем. UI-библиотека выбирается ресёрчем.
