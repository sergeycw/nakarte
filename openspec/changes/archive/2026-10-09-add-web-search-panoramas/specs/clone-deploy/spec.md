# Spec Delta

## ADDED Requirements

### Requirement: Ключ Google для нового приложения

Деплой SHALL передавать значение секрета `GOOGLE_MAPS_API_KEY` в сборку нового приложения переменной `VITE_GOOGLE_MAPS_API_KEY` и только шагу этой сборки: установка зависимостей и тесты `web/` идут без него. Без секрета сборка SHALL проходить с пустым ключом. Отдельного секрета для нового приложения нет.

#### Scenario: Секрет не заведён

- **WHEN** секрета `GOOGLE_MAPS_API_KEY` нет
- **THEN** новое приложение собирается и выкатывается, Maps JavaScript API в нём загружается с пустым ключом

#### Scenario: Секрет заведён

- **WHEN** владелец завёл `GOOGLE_MAPS_API_KEY`
- **THEN** и старый клиент, и новое приложение загружают Maps JavaScript API с этим ключом
