# Spec Delta

## MODIFIED Requirements

### Requirement: Действия с треком

Для каждого трека SHALL быть доступны: переименовать, дублировать (копия с тем же названием, отрезками и точками), развернуть (каждый отрезок в обратном порядке точек), удалить, добавить отрезок (новый пустой отрезок, в котором сразу начинается рисование линии), сохранить в GPX и KML (capability `track-files`), скопировать ссылку на трек. Разворот и дублирование SHALL сохранять разметку маршрута: какие отрезки между опорными точками проложены и с какой активностью.

#### Scenario: Переименовать

- **WHEN** пользователь вводит новое непустое название трека
- **THEN** название меняется в списке; пустое название трек не меняет

#### Scenario: Развернуть

- **WHEN** пользователь разворачивает трек
- **THEN** первая точка каждого отрезка становится последней, длина трека не меняется

#### Scenario: Дублировать

- **WHEN** пользователь дублирует трек
- **THEN** в списке появляется второй трек с тем же названием, отрезками и точками

#### Scenario: Развернуть проложенный трек

- **WHEN** у трека проложен отрезок A–B с активностью «Road bike», трек развернули и перетащили A
- **THEN** B–A перестраивается как «Road bike»

#### Scenario: Добавить отрезок

- **WHEN** пользователь выбирает «Add segment» у трека с одним отрезком и ставит две точки
- **THEN** у трека два отрезка

### Requirement: Действия со списком

Список SHALL позволять: создать новый трек (название — из поля ввода ссылки, если оно не пусто, иначе `New track`) и сразу начать в нём рисование линии, удалить все треки, удалить скрытые треки, создать новый трек из всех видимых (их отрезки и точки в одном треке), скопировать ссылку на все и на видимые треки, сохранить все треки в ZIP.

#### Scenario: Удалить скрытые

- **WHEN** в списке три трека, один из них скрыт, и пользователь выбирает «Delete hidden tracks»
- **THEN** в списке остаются два видимых трека

#### Scenario: Новый трек из видимых

- **WHEN** видимы два трека по одному отрезку и пользователь создаёт новый трек из видимых
- **THEN** появляется трек с двумя отрезками и точками обоих треков

#### Scenario: Новый трек

- **WHEN** пользователь нажимает «New track» и кликает по карте в двух местах
- **THEN** в списке трек `New track` с одним отрезком из двух опорных точек
