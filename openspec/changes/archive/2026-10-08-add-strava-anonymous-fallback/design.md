# Design

## Context

Мотивация — `proposal.md`. Прокси (`workers/cors-proxy`) ставит куки на тайлы `content-*.strava.com/identified/globalheat/` из `src/strava.js` и помечает источник `X-Strava-Cookies`. Замеры 2026-10-08 без кук, тайл Тбилиси: `heatmap-external-{a,b}.strava.com/tiles/{all,run}/hot/{z}/{x}/{y}.png` — `200` на z8–z12 при `px=256` и до z11 при `px=512`; z12 `px=512` и z13 — `403` (`text/plain`); тайл без треков — `404`, как и у адреса по сессии. Тайл z12 `px=256` совпал с тайлом по сессии по размеру (2079 Б).

## Goals / Non-Goals

**Goals:**

- Слои Strava не пустеют на обзорных зумах, когда сессии нет или она умерла.

**Non-Goals:**

- Детализация выше z12 без сессии: Strava её без входа не отдаёт.
- Изменения клиента (`maxNativeZoom`, отдельный анонимный слой).

## Decisions

1. **Подмена в прокси, а не второй слой в клиенте.** Клиенту не нужно знать про сессию: те же адреса, те же коды слоёв, старые ссылки работают. Альтернатива — `maxNativeZoom: 12` и анонимный адрес в `src/layers.js` — потеряла бы z13–z16, когда сессия жива.

2. **Когда идти на анонимный адрес.** Сразу, если кук нет (`none`): запрос к CloudFront заведомо дал бы `403`. После ответа `401`/`403` на тайл с куками (`session`, `fallback`): так ловятся протухшие `STRAVA_COOKIES` и куки, которые CloudFront перестал принимать раньше срока. Тело первого ответа отменяется до второго запроса. `404` (пустой тайл) не трогается.

3. **Пороги зума — константы из замера**: z12 для `px=256` и для адреса без `px` (Strava тогда отдаёт 256), z11 для `px=512`, другие `px` анонимно не запрашиваются. Если Strava поднимет или опустит порог, выше порога клиент получит её `403` как раньше, ниже — анонимный тайл; меняется одна константа.

4. **Поддомен `a|b|c` — по `(x + y) % 3`**: тайлы распределяются, как у Leaflet `subdomains`, и один тайл всегда идёт на один хост (кеш Strava).

5. **Без кук и сессии, `User-Agent` клиента** — как остальные запросы прокси. На анонимный адрес не уходит ничего из секретов.

## Risks / Trade-offs

- [Strava закроет анонимный адрес] → вернётся нынешнее поведение (`403`, пустой слой); ежедневная проверка смотрит только на `session` и об этом не скажет, но тайлы по сессии от этого не зависят.
- [Лишний запрос на каждый тайл z≤12 с протухшими `STRAVA_COOKIES`] → только пока они заданы и протухли; пауза обновления сессии на это не влияет. Удалить протухший `STRAVA_COOKIES` — `wrangler secret delete`.
