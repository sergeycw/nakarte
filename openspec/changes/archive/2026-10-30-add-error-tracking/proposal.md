# Proposal

## Why

Ошибки приложения у пользователей сейчас не видны никому: в браузере нет трекера, а `prod check` и Workers Logs видят только свои сервисы. Владелец узнаёт о поломке из жалоб знакомых (2026-10-30: «на десктопе не открывается»), без стека и без браузера. Владелец 2026-10-30 выбрал Sentry (опрос: Sentry, PostHog, GlitchTip или свой Worker).

## What Changes

- Сборка прода отправляет в Sentry необработанные ошибки страницы, ошибки рендера React и отказ запуска движка прокладки (в воркере и на главном потоке). Отказ прокладки одного маршрута не отправляется.
- Из отчёта вырезаны координаты и треки: фрагмент и параметры адреса страницы, адреса сетевых запросов, сообщения консоли; IP пользователя не собирается, сессии без ошибок не отправляются.
- Трекер включается только адресом проекта Sentry (DSN) в сборке прода из секрета, как ключ Google. Dev-сервер, browser-тесты, сборка без секрета и чужие форки к Sentry не обращаются.
- Деплой загружает карты исходников (`*.map`) в Sentry токеном из секрета и удаляет их до публикации: в Pages карт нет, а стек в Sentry читается по исходникам.
- e2e подменяет приём отчётов Sentry, как Maps JavaScript API, и проверяет, что отчёт уходит без координат.
- Аккаунт и проект Sentry, DSN и токен заводит владелец; без них деплой проходит как сейчас.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `clone-monitoring`: новые требования «Ошибки в браузере пользователей», «Отчёт без места и треков пользователя», «Запросы к Sentry только с ошибкой».
- `clone-deploy`: новые требования «Секреты Sentry только своим шагам» (DSN — шагу сборки, токен — шагу загрузки карт) и «Карты исходников не публикуются» (без секретов деплой проходит).

## Impact

- `web/`: зависимость SDK Sentry для браузера, запуск трекера до рендера, очистка отчёта, отчёт об отказе движка, адрес проекта в `config.ts`, e2e-заглушка приёма отчётов, тесты.
- `.github/workflows/deploy-pages.yml` и `check-web.yml`: переменная DSN для сборки, внедрение идентификаторов карт, загрузка карт `sentry-cli`, удаление карт и проверка, что их нет в `build/`.
- Внешняя зависимость: Sentry, план Developer (5 тыс. ошибок в месяц, 1 пользователь, история 30 дней, [sentry.io/pricing](https://sentry.io/pricing/), 2026-10-30).
- Секреты GitHub `SENTRY_DSN` и `SENTRY_AUTH_TOKEN`, переменные `SENTRY_ORG` и `SENTRY_PROJECT` — заводит владелец.
- Документы: `AGENTS.md`, `docs/architecture/` (Sentry — новый внешний получатель), `openspec/backlog.md` (риск лимита плана).
