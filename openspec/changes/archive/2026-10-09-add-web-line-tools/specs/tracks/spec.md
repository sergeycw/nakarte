# Spec Delta

## ADDED Requirements

### Requirement: Добавление точек трека

Пункт «Add point» в меню трека SHALL включать постановку точек: каждый клик по карте добавляет треку точку и сразу предлагает её название. По умолчанию название — следующий трёхзначный номер после наибольшего среди названий точек трека (`001`, `002` …; после `999` — пустое). Постановка SHALL продолжаться до Escape или кнопки Done. Скрытый трек SHALL становиться видимым.

#### Scenario: Поставить две точки

- **WHEN** пользователь выбирает «Add point», кликает по карте, подтверждает название `001`, кликает ещё раз и нажимает Escape
- **THEN** у трека две точки `001` и `002` в местах кликов, новые клики точек не ставят

#### Scenario: Своё название

- **WHEN** после клика пользователь вводит название `Camp` и подтверждает
- **THEN** у новой точки название `Camp`

#### Scenario: Номер после наибольшего

- **WHEN** у трека есть точки `003` и `Spring`, и пользователь ставит новую точку
- **THEN** её название по умолчанию — `004`

### Requirement: Меню точки трека

Клик по точке видимого трека SHALL открывать меню с её названием и пунктами Rename (окно с полем названия, пустое название допустимо), Move (следующий клик по карте переносит точку, Escape отменяет), Copy coordinates (в буфер обмена `широта долгота` в градусах с пятью знаками, долгота в пределах ±180) и Delete. При рисовании линии клик по точке трека SHALL ставить опорную точку, а не открывать меню.

#### Scenario: Переименовать точку

- **WHEN** пользователь выбирает Rename у точки `001` и вводит `Pass`
- **THEN** на карте и в ссылке у точки название `Pass`

#### Scenario: Переместить точку

- **WHEN** пользователь выбирает Move у точки и кликает по карте в другом месте
- **THEN** точка стоит в месте клика

#### Scenario: Скопировать координаты

- **WHEN** пользователь выбирает Copy coordinates у точки 41.6912345, 44.7812345
- **THEN** в буфере обмена `41.69123 44.78123`

#### Scenario: Удалить точку

- **WHEN** пользователь выбирает Delete у одной из двух точек трека
- **THEN** у трека одна точка, и после перезагрузки страницы — тоже
