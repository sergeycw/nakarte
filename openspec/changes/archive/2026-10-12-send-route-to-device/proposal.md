# Proposal

## Why

Пользователь хочет отправить проложенный маршрут прямо в приложение часов или велокомпьютера (запрос, переданный владельцем; пункт backlog «Отправка маршрута прямо в приложение часов и велокомпьютера»). Прямой отправки в облако для частного проекта нет ни у Garmin, ни у COROS, а Wahoo владелец 2026-10-12 отложил; все три приложения принимают GPX через «открыть в» или «Поделиться» на телефоне ([ресёрч device-route-sync](../../../research/device-route-sync.md#итог)). Сейчас есть только «Save as GPX…»: файл без высот, без шторки «Поделиться» и без подсказки, что с ним делать дальше.

## What Changes

- Пункт **«Send to device»** в меню трека в списке и в меню «Share track» редактора.
- Пункт собирает **GPX с высотами** (как «Save as GPX with elevation»: COROS без `<ele>` показывает маршрут без высот); если API высот не ответил — GPX без высот и пометка в окне, а не отказ.
- Окно **«Send to device»**: пока файл собирается — ожидание, потом кнопки **«Share»** (только где в браузере есть Web Share) и **«Download»** и короткая инструкция для Garmin Connect, Wahoo и COROS со ссылками на их справку.
- «Share» открывает системную шторку с файлом; если браузер файл не отдаёт (Chrome отвечает отказом на `.gpx`) — файл скачивается; закрытая пользователем шторка ничего не делает.
- Не в этом change: прямая отправка в Wahoo Cloud API, Garmin Courses API, COROS Partner API (решения владельца 2026-10-12), FIT-файлы, ссылки-схемы приложений.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `track-files`: новые требования «Файл для устройства», «Шторка “Поделиться” с откатом на скачивание», «Инструкция для приложений устройств».
- `tracks`: требование «Поделиться треком из панели редактирования» — в меню «Share track» добавляется «Send to device».

## Impact

- Код `web/`: `src/tracks/actions.ts` (действия окна, проп шторки), `src/tracks/TrackExportItems.tsx` (пункт), новое окно в `src/tracks/TrackDialogs.tsx`, состояние окна в `src/state/store.ts`, проп `shareFiles` у `App` (`src/App.tsx`, `src/test/render-app.tsx`); unit- и browser-тесты сценариев.
- Сервисы, форматы ссылок, файлов и автосохранения не меняются; запросы — те же, что у «Save as GPX with elevation».
- Документы: абзац «Треки» в `AGENTS.md`, `docs/architecture/` (реестр решений), `openspec/backlog.md` (пункт об отправке в приложение), таблица changes ресёрча `device-route-sync`.
