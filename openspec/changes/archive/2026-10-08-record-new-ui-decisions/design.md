# Design

## Context

Вопросы — ресёрч `openspec/research/new-ui.md`, раздел «Вопросы владельцу»; рекомендации и цены, на которые владелец отвечал, — там же. Ответы владелец дал в сессии 2026-10-08. Ниже — ответ, что из него следует и где ответа нет.

## Decisions

### UI-библиотека: shadcn/ui

shadcn/ui на Base UI с Tailwind CSS 4, как рекомендовал ресёрч (раздел «UI-библиотека»). Mantine не берём.

### Слои Яндекса: не в первой версии, в backlog

Слоёв «Yandex map» (`Y`) и «Yandex Satellite» (`S`) в новом UI нет: Яндекс отдаёт тайлы в EPSG:3395, а MapLibre рисует растр только в Web Mercator, нужна перепроекция (≈ день). Вернуть их — пункт backlog. Коды `Y` и `S` в старых ссылках и настройках подпадают под требование «Старые коды удалённых слоёв» (`clone-hosting`).

### Тени рельефа из AWS Terrain Tiles, тайлы высот выводятся

Владелец согласился попробовать: отмывку рельефа новая карта берёт из AWS Terrain Tiles (Terrarium, открытые данные). Свои тайлы высот теряют единственного потребителя (высоту под курсором удалили в `record-ui-decisions`) и выводятся из эксплуатации в change переключения: маршрут тайлов Worker'а высот, архив `tiles/elevation-z0-9` в R2, спека `elevation-tiles`, требование «Свои тайлы высот» в `clone-hosting`. API высот остаётся: профиль и GPX с высотами.

### Линейка остаётся

«Measure distance» (трек с отметками расстояния) переносится в новый UI как инструмент трека. Удаляется только азимут.

### Импорт Strava, Garmin Connect и Wikiloc убирается

Сейчас он не работает (backlog, «Отложено»), в новом UI его нет. Импорт файлов и работающих ссылок (Yandex, OSM, SportsTracker, Tracedetrail, nakarte) остаётся.

### Встраивание в iframe не нужно

Параметры `min=` и `autoprofile` новый UI не поддерживает и молча игнорирует в старых ссылках, как `p=` и `j=`.

### Сессии: только автосохранение

Список сессий, `sid=`, `BroadcastChannel` и переключение между вкладками уходят. Остаётся автосохранение рабочего набора — треков и разметки маршрута — в IndexedDB: без него треки пропадают при перезагрузке (сессия старого клиента хранит сами треки, а не только разметку, — `loadSession` в `leaflet.control.sessions`). Подхватывать ли при переключении последнюю сессию старого клиента, владелец явно не ответил; решается в change переключения.

### Wikimapia и сетка советских топокарт убираются

Слоёв `W` и `Ng` в новом UI нет: это свои слои на canvas, а не тайлы, перенос стоил бы ≈ полтора дня. Их коды — под тем же требованием о старых кодах. Маршрут прокси `/wikimapia/` теряет клиента и убирается вместе со старым клиентом.

### Интерфейс только на английском

Как сейчас. Перевода и i18n нет.

### Переключение без новой подложки; разработка на `/next/`

Новое приложение до готовности доступно по `https://nakarte-routing.pages.dev/next/`. На основной адрес оно встаёт, когда перенесено всё, кроме новой подложки (changes 1–8 списка ресёрча); подложка по умолчанию на момент переключения — как в старом клиенте, обычный OpenStreetMap. Подложка — следующим change.

### Движок: CheerpJ, Oracle Always Free — в backlog

Движок остаётся в браузере (CheerpJ). Платный VPS (≈ +$4.4–7 в месяц) порог `record-ui-decisions` не проходит. Серверный BRouter на Oracle Always Free ($0, но Oracle забирает простаивающие инстансы) владелец хочет попробовать отдельно позже — пункт backlog.

### Не решено: слой по умолчанию

Владелец спросил, можно ли взять туристический слой OpenStreetMap. На openstreetmap.org это Tracestrack Topo; тайлы только по ключу, бесплатный тариф — 100 тыс. тайлов в месяц и только некоммерческое использование. Предложение ресёрча (Tracestrack Topo по умолчанию с ключом в секрете прокси и откатом на OSM) ответа не получило; решение — в design change подложки.
