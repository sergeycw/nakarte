## REMOVED Requirements

### Requirement: Токен синхронизации

**Reason**: синхронизация больше не ходит в REST API Cloudflare с токеном: право на один бакет оно не принимает, а право на весь аккаунт — лишнее.
**Migration**: ключи S3 API R2 — требование «Ключи синхронизации»; секреты `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_TILES_TOKEN` синхронизации не нужны.

## ADDED Requirements

### Requirement: Ключи синхронизации

Синхронизация в Cloudflare SHALL читать и писать бакет `nakarte-tiles` через S3 API R2 ключами `R2_ACCESS_KEY_ID` и `R2_SECRET_ACCESS_KEY`, переданными только шагу синхронизации, и SHALL NOT требовать прав R2 на весь аккаунт.

#### Scenario: Ключи с правом на бакет

- **WHEN** у ключей есть только запись в объекты `nakarte-tiles` (и `nakarte-elevation`)
- **THEN** синхронизация читает манифест и заливает тайлы

### Requirement: Ошибка чтения манифеста

Синхронизация SHALL считать манифест пустым, только если объекта `manifest.json` в бакете нет. Любая другая ошибка чтения SHALL останавливать прогон до заливки тайлов и записи манифеста.

#### Scenario: Нет прав на чтение

- **WHEN** чтение `manifest.json` вернуло отказ в доступе
- **THEN** прогон завершается ошибкой, ни тайлы, ни манифест не пишутся

#### Scenario: Первый прогон

- **WHEN** `manifest.json` в бакете нет
- **THEN** синхронизация начинает с пустого манифеста
