# Spec Delta

## ADDED Requirements

### Requirement: Профиль высот трека и отрезка

«Show elevation profile» в меню трека SHALL открывать снизу карты панель с графиком высот вдоль всех отрезков трека, «Show elevation profile for segment» в меню на карте — вдоль редактируемого отрезка. Высоты SHALL браться из API высот в точках через равный шаг 10–50 м, не больше 10 000 точек, конец линии входит всегда. Расстояние между отрезками трека в профиль не входит. Новый профиль заменяет открытый, кнопка закрывает. Панель SHALL показывать атрибуцию данных высот.

#### Scenario: Профиль трека

- **WHEN** у трека два отрезка по 1 км в 5 км друг от друга, и пользователь выбирает «Show elevation profile»
- **THEN** снизу открывается профиль длиной 2.00 km, в API уходит один запрос, в панели — ссылка на источник данных высот

#### Scenario: Профиль отрезка

- **WHEN** пользователь кликает правой кнопкой по линии трека с двумя отрезками и выбирает «Show elevation profile for segment»
- **THEN** профиль строится только по этому отрезку, редактирование отрезка продолжается

#### Scenario: Трек без линий

- **WHEN** у трека только точки, и пользователь выбирает «Show elevation profile»
- **THEN** появляется сообщение `Track is empty`, панель не открывается, запросов нет

### Requirement: Сводка профиля

Панель профиля SHALL показывать расстояние, набор и сброс высоты, наименьшую и наибольшую высоту, высоту начала и конца, средний и наибольший уклон подъёма и спуска в градусах. Набор и сброс SHALL считаться по высотам, упрощённым с допуском 5 м: колебания меньше допуска не суммируются. Если без данных больше 2 % точек, SHALL показываться `Some elevation data missing`, а затронутые значения — с `~`; без данных совсем — `No elevation data`.

#### Scenario: Подъём и спуск

- **WHEN** высоты вдоль профиля 100, 200 и 150 м
- **THEN** набор 100 m, сброс 50 m, наименьшая 100 m, наибольшая 200 m

#### Scenario: Мелкие колебания

- **WHEN** высоты вдоль профиля 100, 103, 100, 103, 100 м
- **THEN** набор и сброс — 0 m

#### Scenario: Точки без данных

- **WHEN** API ответил `NULL` на часть точек профиля
- **THEN** график рвётся на этих точках, наименьшая высота не 0, в сводке — `Some elevation data missing`

### Requirement: Курсор профиля и карта

Наведение на график SHALL показывать курсор с высотой, расстоянием от начала и уклоном и метку в той же точке линии на карте; наведение мыши на линию профиля на карте — курсор на графике в ближайшей точке. Выделение участка графика мышью SHALL давать сводку участка и подсвечивать участок на карте; клик без сдвига снимает выделение. Двойной клик по графику SHALL переводить карту в эту точку.

#### Scenario: Курсор на графике

- **WHEN** пользователь наводит мышь на середину графика профиля прямой линии
- **THEN** на карте метка в середине линии, у курсора — высота и расстояние вдвое меньше длины профиля

#### Scenario: Курсор над линией

- **WHEN** пользователь наводит мышь на конец линии профиля на карте
- **THEN** курсор графика стоит у правого края

#### Scenario: Выделение участка

- **WHEN** пользователь тянет мышью по графику от четверти до половины длины
- **THEN** сводка показывает расстояние выделенного участка, участок подсвечен на карте; клик по графику возвращает сводку всего профиля

### Requirement: Профиль следует за треком

Изменение линий трека под открытым профилем — правка, ответ роутера, разворот — SHALL перестраивать профиль, когда изменений нет 1 секунду и в его линиях нет ожидающих отрезков; до этого виден прежний профиль. Удаление трека или отрезка профиля SHALL закрывать профиль. Смена цвета, названия и видимости профиль не перестраивает.

#### Scenario: Правка во время профиля

- **WHEN** открыт профиль отрезка, и пользователь перетаскивает опорную точку, а роутер прокладывает отрезок
- **THEN** после ответа роутера профиль перестраивается по новой линии одним запросом к API высот

#### Scenario: Удаление трека

- **WHEN** открыт профиль трека, и трек удалили
- **THEN** панель профиля закрывается

### Requirement: Ошибка сервиса высот в профиле

Ошибка сети или ответ API высот не `200` SHALL показываться в панели профиля текстом `Failed to get elevation data: <причина>` с кнопкой Retry, которая повторяет запрос. На `429` причина SHALL быть `too many requests, try again in a minute`.

#### Scenario: Сервис недоступен

- **WHEN** запрос высот профиля упал ошибкой сети, а повтор прошёл
- **THEN** сначала панель показывает `Failed to get elevation data: network error` и Retry, после Retry — график

#### Scenario: Слишком частые запросы

- **WHEN** API высот ответил `429`
- **THEN** панель показывает `Failed to get elevation data: too many requests, try again in a minute`
