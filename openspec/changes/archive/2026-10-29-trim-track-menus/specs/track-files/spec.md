## ADDED Requirements

### Requirement: Экспорт трека

Трек SHALL сохраняться в GPX 1.1 пунктом «Save as GPX» (отрезки — `trkseg`, точки — `wpt`) и в KML 2.2 пунктом «Save as KML» (отрезки — `LineString`, точки — `Point`) в UTF-8, координаты с шестью знаками. Отрезок, пересекающий меридиан 180°, SHALL делиться на два у меридиана. Пустой трек SHALL давать `Track is empty, nothing to save` вместо файла.

#### Scenario: Сохранить в GPX

- **WHEN** пользователь сохраняет трек с отрезками и точками в GPX и открывает файл снова
- **THEN** открывается трек с теми же отрезками и точками (координаты до шести знаков)

## MODIFIED Requirements

### Requirement: GPX с высотами

«Save as GPX» SHALL добавлять каждой точке отрезков и каждой точке трека `<ele>` — высоту из API высот с одним знаком после точки; точка, на которую API ответил `NULL`, остаётся без `<ele>`. Ошибка сети или ответ не `200` SHALL давать тот же GPX без `<ele>` и без сообщения. Пустой трек SHALL давать `Track is empty, nothing to save` без запросов. Отдельного пункта «with elevation» в меню нет.

#### Scenario: Сохранить с высотами

- **WHEN** пользователь сохраняет в GPX трек с отрезком из трёх точек и одной точкой трека
- **THEN** в файле у трёх `trkpt` и у `wpt` есть `<ele>` с высотами, которые вернул API, координаты — как в обычном GPX

#### Scenario: Точка без данных

- **WHEN** API ответил `NULL` на одну точку отрезка
- **THEN** у этой `trkpt` нет `<ele>`, у остальных есть

#### Scenario: Сервис недоступен

- **WHEN** запрос высот при сохранении в GPX упал ошибкой сети
- **THEN** сохраняется GPX без `<ele>`, сообщения нет

## REMOVED Requirements

### Requirement: Экспорт треков

**Reason**: ZIP всех треков удалён (владелец 2026-10-29); экспорт одного трека — новое требование «Экспорт трека».

**Migration**: все треки — ссылкой «Copy link for all tracks»; один трек — «Save as GPX» или «Save as KML».

### Requirement: Файл для устройства

**Reason**: «Send to device» удалён (владелец 2026-10-29).

**Migration**: маршрут на устройство — файлом «Save as GPX», он с высотами (требование «GPX с высотами»).

### Requirement: Шторка «Поделиться» с откатом на скачивание

**Reason**: шторка была кнопкой окна «Send to device», окно удалено (владелец 2026-10-29).

**Migration**: файл «Save as GPX» скачивается; в приложение устройства его открывают средствами системы.

### Requirement: Инструкция для приложений устройств

**Reason**: инструкция была частью окна «Send to device», окно удалено (владелец 2026-10-29).

**Migration**: шаги для Garmin Connect, Wahoo и COROS — в ресёрче `openspec/research/device-route-sync.md`.
