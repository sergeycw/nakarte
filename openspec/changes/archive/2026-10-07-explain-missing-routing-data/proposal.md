# Proposal

## Why

Когда для района нет тайлов BRouter, пользователь видит «Routing failed: datafile E30_N55.rd5 not found». Имя файла ему ничего не говорит, непонятно, что сломалось и чинится ли это.

## What Changes

- Ошибку BRouter об отсутствующем тайле приложение показывает как «Routing failed: no routing data for this area», в обоих режимах движка (сервер и браузер).
- Остальные ошибки роутера показываются как раньше, с текстом BRouter.

## Capabilities

### New Capabilities

### Modified Capabilities

- `routing`: требование «Ошибка прокладки даёт прямой отрезок» получает отдельный текст для района без данных.

## Impact

- `src/lib/brouter/index.js`: перевод текста ошибки, один файл форка.
- Пункт бэклога про понятное сообщение закрывается.
