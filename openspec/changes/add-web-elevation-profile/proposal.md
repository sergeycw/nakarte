# Proposal

## Why

Новое приложение на `/next/` открывает, прокладывает и правит треки, но не показывает, сколько на маршруте набора высоты и где подъёмы, и не умеет сохранять GPX с высотами — а старый клиент умеет (профиль трека и отрезка, «Save as GPX with added elevation (SRTM)»). Без этого переключение на новое приложение (change 9) отнимает функцию; API высот ради неё и оставлен ([record-new-ui-decisions](../archive/2026-10-08-record-new-ui-decisions/design.md#тени-рельефа-из-aws-terrain-tiles-тайлы-высот-выводятся)). Это change 7 из [списка ресёрча](../../research/new-ui.md#changes-по-порядку).

## What Changes

- Профиль высот трека (пункт меню трека «Show elevation profile») и отрезка (пункт «Show elevation profile for segment» меню опорной точки и линии на карте): панель снизу с графиком и сводкой — расстояние, набор и сброс, высоты, уклоны; курсор на графике показывает точку на карте, курсор над линией на карте — точку на графике; выделение участка на графике мышью даёт сводку участка и подсвечивает его на карте.
- Профиль следует за своим треком: правка линии, ответы роутера, разворот трека перестраивают его (с паузой, без запросов на каждое движение), удаление трека или отрезка закрывает.
- Ошибка или недоступность сервиса высот — сообщение в панели с повтором; точки без данных — разрывы графика и пометка в сводке.
- «Save as GPX with elevation» в меню трека: GPX, где у каждой точки линии и точки трека есть `<ele>`; без ответа сервиса файл не сохраняется.
- Расчёт профиля исправляет дефекты старого клиента: конец линии не теряется при выборке, последняя точка входит в набор высоты, точки без данных не попадают в шкалу как 0, разрыв между отрезками трека не считается расстоянием.
- Тесты без сети: unit — выборка, сводка, разбор ответа API, GPX с высотами; browser mode — профиль в `App` с заглушкой `fetch`; e2e — профиль и GPX со сборкой клона и заглушкой сервиса высот.
- Не входит: тайлы высот (выводятся в change переключения), Worker высот и его контракт, старый клиент, зум профиля пальцами и выделение участка на телефоне, полировка вида (change `polish-web-ui`).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `tracks`: новые требования — профиль высот трека и отрезка, профиль следует за треком, ошибка сервиса высот; в «Действия с треком» добавляются профиль и GPX с высотами.
- `track-files`: новое требование — GPX с высотами.
- `route-editing`: в «Меню опорной точки и линии» добавляется «Show elevation profile for segment».

## Impact

- Новый код: `web/src/elevation/` — запросы к API высот, выборка и сводка профиля без карты, панель профиля, курсор и выделение на карте.
- Изменения: `web/src/tracks/export.ts` (высоты в GPX), `actions.ts`, `TrackList.tsx`, `web/src/routing/MapMenu.tsx`, `EditPanel.tsx`, `web/src/tracks/PointPanel.tsx` (место над профилем), `web/src/map/BaseMap.tsx`, `web/src/layers/style.ts`, `web/src/state/store.ts`, `web/src/config.ts` (атрибуция данных высот), `App.tsx`, тестовые помощники, e2e-фикстура сети; `AGENTS.md`; ресёрч `new-ui.md` (7 — сделан) — при архиве.
- Внешние сервисы: только существующий API высот (спека `elevation-api`), Worker и его `ALLOWED_ORIGINS` не меняются; с dev-сервера (8769) и `vite preview` (4173) API недоступен — живая проверка на проде после деплоя.
