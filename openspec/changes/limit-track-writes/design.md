# Design

## Context

Цены и формулы — `openspec/research/security-audit.md`, п. 3. Клиент (`copyTracksLinkToClipboard` в `track-list.js`) склеивает через `/` строки `saveNktk`: версия, protobuf с дельтами координат (сетка `arcUnit` ≈ 2.4 м), base64url с `-`, `_` и паддингом `=`. Трек упрощается перед сохранением (`simplifyKeepingWaypoints`, допуск ≈ 2.4 м).

## Goals / Non-Goals

**Goals:** запись с одного IP ограничена по числу и объёму; в хранилище попадают только строки ссылок; мусор после атаки можно найти без чтения тел.

**Non-Goals:**
- Чистка хранилища: инструмента нет, метаданные — только предпосылка.
- Распределённый клиент: счётчик по IP и по локации, как остальные.
- Разбор `nktk` на сервере: алфавита достаточно, чтобы хранилище не было файлообменником для произвольных байт; base64 произвольного файла алфавит пройдёт, но потолок 2 МиБ и 10 записей в минуту ограничивают объём.

## Decisions

- **10 записей в минуту.** Пользователь копирует ссылку единицы раз за сессию; запись повторного ключа тоже тратит счётчик — это проще и не мешает. С IP: 432 тыс. записей в месяц × 2 МиБ ≈ 906 ГБ ≈ +$13.6 за месяц атаки вместо +$408; класс A в бесплатном миллионе. Порядок: `Origin` → общий счётчик → для `POST` счётчик записей → чтение тела. Отдельный `namespace_id`, а не общий счётчик с меньшим лимитом: чтения ссылок (`GET`) не должны упираться в лимит записей.
- **2 МиБ.** 3–4 байта на точку упрощённого трека — сотни тысяч точек, это ссылка на десяток больших треков. Альтернатива 1 МиБ вдвое снижает худший случай, но ближе к реальным многотрековым ссылкам; 10 МиБ было взято с запасом без замера (`add-track-storage`).
- **Алфавит `[A-Za-z0-9_\-=/]`.** Совпадает с выходом `urlSafeBase64.encode` (паддинг `=` клиент не срезает) и разделителем `/`. Проверка — после потолка размера и до сверки ключа: на мусор не тратится md5.
- **`customMetadata.created`.** Привязка R2 `put` принимает его без лишних операций; листинг с `include: ['customMetadata']` вернёт время без `GET` тел. Версию `nktk` не пишем: в теле их может быть несколько.

## Risks / Trade-offs

- [Ссылка на очень много треков больше 2 МиБ] → клиент покажет «track is too big», как раньше на 10 МиБ; поднять — одна константа.
- [Старые объекты без `created`] → их три (Cloudflare GraphQL Analytics, 2026-10-08), отличить легко.
