# Proposal

## Why

Новое приложение на `/next/` показывает только OpenStreetMap ([add-web-skeleton](../archive/2026-10-08-add-web-skeleton/design.md)), а старый клиент — 34 слоя с переключателем, хоткеями, своими слоями по URL и кодами слоёв в ссылке `l=`. Это change 3 из [списка ресёрча](../../research/new-ui.md#changes-по-порядку): без слоёв и разбора адреса нельзя переносить треки (change 4) — ссылки на треки несут `m=` и `l=`, и состояние приложения (Zustand) появляется именно здесь.

## What Changes

- Каталог растровых слоёв на TypeScript с кодами старого клиента: 30 слоёв из [src/layers.js](../../../src/layers.js) без Яндекса (`Y`, `S`), Wikimapia (`W`) и сетки `Ng` (решения владельца). Группы, порядок наложения, слои «в списке по умолчанию», хоткеи, атрибуция — как в старом клиенте; обрезка по контуру заменяется прямоугольником `bounds` источника.
- Новый оверлей «Relief shading» — отмывка рельефа из AWS Terrain Tiles (Terrarium) слоем `hillshade` MapLibre.
- Переключатель слоёв на shadcn поверх карты: подложка, оверлеи, настройка списка (какие слои показывать, хоткеи), свои слои по URL с проверкой CORS и предложением прокси.
- Модуль адреса `hash.ts` и стор Zustand: чтение и запись `m=` и `l=` в формате старого клиента, включая коды удалённых слоёв и свои слои `-cs…`; зум MapLibre = зум Leaflet − 1. Прочие параметры адреса сохраняются нетронутыми для следующих changes.
- Настройки слоёв и последний выбор — под своими ключами `localStorage`; старые `leafletLayersSettings` читаются при первом запуске.
- Тост ошибки тайлов — для любого слоя, а не только OSM.
- Тесты без сети: тайлы всех слоёв в browser mode и e2e подменяются фикстурой, любые другие запросы мимо `localhost` валят тест; `hash.ts` — на наборе реальных старых ссылок.
- Старый клиент не меняется.

## Capabilities

### New Capabilities

- `map-layers`: слои карты нового приложения — каталог, выбор подложки и оверлеев, настройка списка и хоткеи, свои слои по URL, слои в адресе (`l=`) и в `localStorage`, отмывка рельефа.

### Modified Capabilities

- `web-client`: вид карты читается из адреса `m=` и пишется в него; тост ошибки тайлов — для любого слоя.

## Impact

- Новый код: `web/src/layers/` (каталог, стиль, настройки, свои слои), `web/src/state/` (`hash.ts`, стор), компоненты переключателя, компоненты shadcn (`popover`, `dialog`, `checkbox`, `input` и т. п.).
- Изменения: `web/src/App.tsx`, `web/src/map/BaseMap.tsx`, `web/src/map/osm-style.ts` (уходит в стиль из каталога), `web/e2e/fixtures.ts`, тесты, `web/package.json` (`zustand`), `AGENTS.md` (подвохи слоёв).
- Внешние сервисы: тайлы слоёв — с хостов провайдеров, Strava и Tsvetkov — через CORS-прокси клона (`config.corsProxyUrl`); роли прокси не расширяются.
- Прод: `/next/` получает слои; `/`, Pages Functions, Worker'ы и CI-workflow не меняются.
