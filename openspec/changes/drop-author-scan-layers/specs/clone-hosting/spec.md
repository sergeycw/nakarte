# Spec Delta

## ADDED Requirements

### Requirement: Без слоёв сканов автора

Сборка клона SHALL не предлагать слои с кодами T, D, N, A, J, C, F, B, K, U, R, E25m, NT1, NT5, T25, MN25, Pur (сканы карт на тайлах автора): их нет в выборе слоёв, они не включаются хоткеями и не запрашивают тайлы `tiles.nakarte.me`. Сборка без цели SHALL показывать эти слои как апстрим.

#### Scenario: Выбор слоёв в клоне

- **WHEN** пользователь клона открывает выбор слоёв
- **THEN** в нём нет «Soviet topo maps (AtloMaps)», «Topo 10km», «GGC 2 km» и остальных слоёв из списка

#### Scenario: Ссылка со скрытым слоем

- **WHEN** клон открыт по адресу с `l=O/F` (F — скрытый слой GGC 500m)
- **THEN** карта открывается со слоем OpenStreetMap без ошибок, запросов к `tiles.nakarte.me` нет

#### Scenario: Сборка апстрима

- **WHEN** приложение собрано без `NAKARTE_TARGET`
- **THEN** все 17 слоёв доступны, как в апстриме
