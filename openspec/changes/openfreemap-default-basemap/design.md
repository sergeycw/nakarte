# Design

## Context

- Подложка по умолчанию — `DEFAULT_SELECTION = { base: 'Tt' }` в `web/src/layers/selection.ts`; там же `FALLBACK_BASE = 'O'`.
- Откат: `showTileError` в `web/src/App.tsx` откатывает только `code === DEFAULT_SELECTION.base` через `fallBackBase` стора; `basemapFallback` помнит, с какой подложки откатились, а `savedSelection` пишет её в `l=` и `localStorage`, пока на карте `FALLBACK_BASE` (`web/src/state/store.ts`). Если просто поменять умолчание на `Of`, у тех, кто сам выбрал `Tt`, откат на OSM молча пропал бы.
- Ошибка источника — событие `error` карты с `sourceId` (`BaseMap.tsx`, `onError`); у `Of` источник векторный с TileJSON `https://tiles.openfreemap.org/planet` (`catalog.ts`).
- Круг «топокарта» справа — первый код группы `Topo layers` в `QUICK_BASE_GROUPS` (`web/src/layers/quick-layers.ts`), сейчас `Tt`; картинка — `web/src/layers/thumbnails/<код>.webp` из `scripts/layer-thumbnails.mjs`. `quickTarget` отдаёт кругу текущую подложку группы, иначе запомненную, иначе первый код группы: с умолчанием `Of` и первым кодом `Tt` круг показывал бы картинку Tracestrack, а после ухода на другую группу возвращал бы на Tracestrack — и тратил бы квоту.
- Почему `Of` не сделали умолчанием раньше: у OpenFreeMap нет SLA, откат с неё отложили до отдельного change (design [add-vector-outdoor-style](../archive/2026-10-12-add-vector-outdoor-style/design.md), «Non-Goals» и «Риски»). Владелец 2026-10-30 выбрал откат `Of` → `Tt` (опрос: Tracestrack, OpenStreetMap или без отката).

## Goals / Non-Goals

**Goals:**

- Новый пользователь видит `Of` и не тратит квоту Tracestrack, пока OpenFreeMap отвечает.
- Сбой OpenFreeMap не оставляет пустую карту: откат на `Tt`, сбой и его — на `O`.

**Non-Goals:**

- Перевод тех, кто уже сохранил `Tt`, на `Of`: сохранённый выбор важнее умолчания (спека, «Подложка по умолчанию»), таких — владелец и тестеры.
- Кеш тайлов Tracestrack на краю и платный тариф — варианты из `load-capacity.md`, не здесь.
- Правка стиля `Of`.

## Decisions

### Цепочка отката — таблица, а не одна константа

`FALLBACK_BASE` заменяется таблицей `BASEMAP_FALLBACKS = { Of: 'Tt', Tt: 'O' }` в `selection.ts`: следующая подложка для каждой, у которой откат есть. `showTileError` откатывает любой `code` из таблицы, а не только умолчание; тост — `<название code> is unavailable` / `Switched to <название следующей>`.

- `fallBackBase(code)`: `selection.base === code` и у `code` есть следующая — переключить на неё; `basemapFallback` остаётся первой подложкой цепочки (`basemapFallback ?? code`): после `Of` → `Tt` → `O` в `l=` и в сохранённом выборе — `Of`.
- `savedSelection`: пока `basemapFallback` задан и текущая подложка — звено цепочки после него, сохраняется `basemapFallback`. Любой другой выбор (сама выбрала подложку, ссылка `l=`) сбрасывает откат, как сейчас.
- Петли нет: у `O` следующей нет, ошибки `O` — обычный тост.
- Альтернатива — откат `Of` → `O` напрямую: проще, но переносит трафик сбоя на OSM, против правил OSMF; владелец выбрал `Tt`.

### Ошибка векторного источника

Описание тайлов (TileJSON) и `.pbf` приходят тем же событием `error` карты с `sourceId = 'Of'`; `layerCodeOfSource` даёт `Of`. Что MapLibre шлёт на отказ TileJSON (статус, есть ли `sourceId`) — проверить browser-тестом с подменённым ответом TileJSON (`/__status__/503/…` dev-сервера Vitest или `transformRequest`); если `sourceId` нет — ловить по адресу запроса в ошибке. `404` `.pbf` у OpenFreeMap не бывает в покрытии (пустой тайл), но правило «`404` — не откат» общее.

### Круг топокарты — `Of`

`QUICK_BASE_GROUPS[0].codes` — `['Of', 'Tt', 'Otm', 'Oso', 'Ocm', 'Co']`: круг показывает `Of`, нажатие без памяти выбирает `Of`, `Tt` — в меню группы и в Configure layers (галочка по умолчанию, как у слоёв групп, `listedByDefault`). **[агент]** Альтернатива — оставить `Tt` первым: круг с картинкой Tracestrack при включённой `Of` и возврат на `Tt` после смены группы, то есть трата квоты; отклонена.

Картинка `Of.webp` — то же место и зум, что у `Tt` (`PLACES` скрипта: 42.47, 44.48, z13), отрисовка MapLibre стилем `Of`: скрипт сейчас векторные подложки не снимает, способ — в истории change `add-vector-outdoor-style`. `Tt.webp` и место `Tt` в `PLACES` удаляются: превью `Tt` больше не нужно (неиспользуемое удаляется, `AGENTS.md`, «Апстрим»). Вид круга владелец видит скриншотом до merge.

### Тесты

- unit: `selection` (умолчание `Of`, таблица отката), `store` (цепочка `Of` → `Tt` → `O`, `basemapFallback` остаётся `Of`, выбор сбрасывает откат), `sync` (первый заход — `l=Of`; следующий заход после отката пробует `Of`), `quick-layers` (круг топокарты — `Of`), `catalog` (порядок списка без кнопок столбца).
- browser: `App` — «OpenFreeMap недоступен», «Недоступны обе», «Нет ключа или квоты» (`l=Tt`), «Тайла нет»; `LayerSwitcher` — «Превью без настроек», «Кнопок столбца в настройке нет».
- e2e: `map-layers` — «Первый заход без настроек» (тайлы `Of` есть, `Tt` нет), откат; `web-client` — «Первый заход» (подпись OpenFreeMap), «Ошибка подложки Tracestrack» (`l=Tt`), «Ошибка подложки OpenFreeMap»; остальные e2e, которые ждут `Tt` по умолчанию, — поправить ожидания или явный `l=Tt`.

## Risks / Trade-offs

- [OpenFreeMap без SLA, может закрыться] → откат на `Tt` держит карту рабочей; при долгом простое — квота Tracestrack кончится за дни, дальше `O`. Сигнала владельцу о сбое `Of` нет, кроме Sentry (откат — не ошибка) и жалоб; ежедневная проверка `Of` по образцу `tracestrack check` — backlog.
- [Векторная подложка тяжелее для слабых устройств] → тайлы `.pbf` легче растра по трафику, но рисуются GPU; на слабом телефоне дольше первый кадр. Замер — при проверке на телефоне (backlog, «Проверка в Firefox, Safari и на телефоне»).
- [Вид по умолчанию меняется] → другие цвета и подписи у новых пользователей; решение владельца.
- [Сохранённый `Tt` у старых браузеров] → тратят квоту, как раньше; это владелец и тестеры.

## Migration Plan

Без шагов владельца: деплой выкатывает новое умолчание, сохранённые выборы не трогаются. Откат — revert и push.
