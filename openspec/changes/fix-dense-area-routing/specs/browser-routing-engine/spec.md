# Spec Delta

## MODIFIED Requirements

### Requirement: Паритет с серверным BRouter

Движок в браузере SHALL давать для тех же точек, профиля и данных тот же маршрут, что серверный BRouter той же версии.

#### Scenario: Эталонные маршруты

- **WHEN** 6 эталонных запросов из `experiments/wasm/routes.json` считаются в браузере
- **THEN** длина и число точек каждого маршрута совпадают с эталоном сервера из `experiments/wasm/baseline/`

#### Scenario: Плотный город

- **WHEN** в браузере считается маршрут через центр Берлина `13.38,52.51|13.41,52.52` с профилем `mtb`
- **THEN** маршрут построен, его длина совпадает с серверным BRouter на том же тайле (2691 м на тайлах 2026-10-06)

## ADDED Requirements

### Requirement: Пустой результат — ошибка

Если движок в браузере не нашёл маршрут и не сообщил причину, он SHALL вернуть ошибку «no route found», а не пустой маршрут.

#### Scenario: Движок вернул пустой трек

- **WHEN** движок завершил расчёт без ошибки, но маршрут не содержит точек
- **THEN** приложение получает ошибку «no route found», отрезок остаётся прямым с уведомлением «Routing failed: no route found»
