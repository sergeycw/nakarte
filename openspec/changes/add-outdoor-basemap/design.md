# Design

## Context

Зачем — [proposal](proposal.md), поведение — спеки change. Варианты подложки, цены и риски — [ресёрч](../../research/new-ui.md#подложка-по-умолчанию-векторная-туристическая), каталог и прокси слоёв — архив [add-web-map-layers](../archive/2026-10-08-add-web-map-layers/design.md), тост ошибки тайлов — [add-web-skeleton](../archive/2026-10-08-add-web-skeleton/design.md#панель-и-тост), `LAYER_HOSTS` и `ALLOWED_ORIGINS` — [retire-old-client-services](../archive/2026-10-09-retire-old-client-services/design.md#прокси-без-wikimapia-слои--только-те-что-шлёт-приложение).

**Решение владельца 2026-10-09:** подложка по умолчанию — Tracestrack Topo (ключ в секрете прокси, откат на OSM), а не свой векторный стиль на OpenFreeMap. Это закрывает открытый вопрос ресёрча.

Что проверено 2026-10-09:

- Адрес слоя на openstreetmap.org — `https://tile.tracestrack.com/topo__/{z}/{x}/{y}.webp?key={apikey}`, `maxZoom: 19`, тайл Leaflet по умолчанию 256 px ([layers.yml](https://github.com/openstreetmap/openstreetmap-website/blob/master/config/layers.yml), [leaflet.osm.js](https://github.com/openstreetmap/openstreetmap-website/blob/master/vendor/assets/leaflet/leaflet.osm.js)). По [документации Tracestrack](https://tracestrack.com/docs/): имя карты — `topo_` плюс код языка, `_` — без перевода подписей (отсюда `topo__`); ключ — параметр `key`; `Referer` проверяется, только если у ключа задан список; суффикс `@2x` — тайл повышенной плотности, `@1x` — уменьшенный до 256×256; рекомендуется `webp`; ошибки — `403` (ключ отсутствует, неверен, заблокирован или `Referer` не совпал), `429` (лимит частоты ключа), `404` (вне сетки или неизвестная карта), `502` (сбой источника). Что бывает при исчерпании бесплатной квоты, документация не говорит.
- Без ключа `tile.tracestrack.com` отвечает `403 text/plain` без `Access-Control-Allow-Origin` (`curl -IL -H 'Origin: https://nakarte-routing.pages.dev'`, редиректов нет). Прямой запрос из браузера с ключом в адресе отдал бы ключ всем, поэтому — только через прокси, который CORS ставит сам.
- Условия: бесплатный тариф — только некоммерческое использование, 100 тыс. кредитов в месяц, растровый тайл — 1 кредит за успешный вызов ([tracestrack.com](https://www.tracestrack.com/), ресёрч). Подпись «Maps © Tracestrack» ресёрч взял из [условий](https://www.tracestrack.com/en/terms) 2026-10-08; сегодня на этой странице и в `/terms-of-service/` текста про атрибуцию не нашлось, подпись всё равно ставим, вместе с © OpenStreetMap contributors, как у openstreetmap.org.
- MapMagic (пример из backlog) по умолчанию рисует свой растр `tile.mapmagic.app` (512 px, nginx за CDN Yandex Cloud) — то же, что в ресёрче; открытого API у него нет.
- Ключа у агента нет: тайлы с ключом, `Cache-Control` ответа и размер тайла по умолчанию не проверены (Проверки, после шага владельца).

## Goals / Non-Goals

**Goals:**
- Новый заход без `l=` и без сохранённого выбора — на Tracestrack Topo; ссылки `l=O` и сохранённый выбор не меняются.
- Ключ Tracestrack не покидает Worker прокси.
- Без ключа, при исчерпанной квоте или сбое Tracestrack карта остаётся рабочей: OpenStreetMap с тостом.

**Non-Goals:**
- Свой векторный стиль на OpenFreeMap, шрифты, `glyphs` — вариант, который владелец не выбрал; остаётся в ресёрче («Рекомендация на потом») и backlog.
- Кеш тайлов Tracestrack на стороне Cloudflare (Cache API на `*.workers.dev` не работает) — backlog, если квоты не хватит.
- Перевод подписей (`topo_ru`, `topo_auto`) — сначала посмотреть на живые тайлы с ключом.

## Decisions

Решения, которых нет в ресёрче, архивах и задаче change, помечены **[агент]**.

### Слой `Tt` в каталоге **[агент]**

Код `Tt` — двухбуквенный, как `Mt` и `Gh`; ни у старого клиента, ни в фикстуре реальных старых ссылок `src/state/fixtures/old-links.txt` такого нет. Подложка группы `Default layers`, `isDefault: true`, первая в `ORDER` — первой строкой переключателя. Адрес — `viaCorsProxy(…, 'https://tile.tracestrack.com/topo__/{z}/{x}/{y}{ratio}.webp')`, `tileSize: 256`, `maxzoom: 19`, как на openstreetmap.org: тайлов на экран столько же, сколько у OSM (оценка ресёрча — 50–150 на заход). `{ratio}` MapLibre подставляет `@2x` на экранах с плотностью от 2 — тайл того же кредита, но чёткий; так уже сделаны слои Thunderforest. Без перевода подписей (`topo__`), как у openstreetmap.org.

Атрибуция — `Maps © Tracestrack` (ссылка на `https://www.tracestrack.com/`) и © OpenStreetMap contributors. Слой растровый: бандл и память на телефоне не меняются по сравнению с OSM, замер как у векторного стиля не нужен.

### Ключ — в прокси, только для тайлов `topo__`

Прокси узнаёт тайл по хосту `tile.tracestrack.com` и пути `^/topo__/\d+/\d+/\d+(@2x)?\.webp$`, отбрасывает запрос клиента после пути (там мог бы оказаться чужой `key`) и шлёт `?key=<TRACESTRACK_KEY>`. Узкий шаблон **[агент]**: ключ тратится только на то, что показывает приложение, — векторные тайлы и API высот Tracestrack стоят по 6 кредитов, а через открытый прокси их мог бы звать кто угодно с поддельным `Origin`. Прочие адреса Tracestrack идут как любой хост, без ключа.

- Без секрета — `503 Tracestrack key is not set` с CORS, без запроса наружу **[агент]**: клиент видит ошибку слоя и откатывается, в Tracestrack не уходит запрос без ключа.
- `Location` ответа на тайл проходит без `key` **[агент]**: перезапись в форму прокси иначе отдала бы ключ клиенту; Tracestrack на тайлы не редиректит, но проверить это без ключа нельзя.
- `Cache-Control`: если у ответа `200` его нет, прокси ставит `public, max-age=86400` **[агент]** — повторный заход того же браузера не тратит кредиты. Есть — не трогает.
- `Referer` прокси не пересылает (`FORWARDED_REQUEST_HEADERS`), поэтому список `Referer` у ключа владелец оставляет пустым: его роль играет `ALLOWED_ORIGINS` прокси.
- Хост — в `LAYER_HOSTS` (лимит слоёв 1 200 в минуту), иначе карта упиралась бы в лимит 300 прочих хостов.

### Откат на OpenStreetMap — до перезагрузки **[агент]**

Ошибка тайла `Tt` с любым статусом, кроме `404`, или без статуса, когда `Tt` — текущая подложка, переключает подложку на `O`, оставляет оверлеи и даёт тост `Tracestrack Topo is unavailable` / `Switched to OpenStreetMap` (постоянный id — один тост на серию). Ошибка тайла не различает «нет ключа», «кончилась квота» и «сбой»; любая из них на подложке делает карту пустой, а запасная карта лучше серого фона. `404` — «тайла нет», как у остальных слоёв.

Откат не записывается как выбор пользователя: стор помнит, с какой подложки откатился (`basemapFallback`), и в `localStorage` уходит выбор с ней, пока подложка — та, на которую откатились. Явный выбор подложки или `l=` из адреса сбрасывает откат. Иначе каждый заход в день без ключа или в конце месяца без квоты навсегда пересаживал бы пользователя на OSM. В адресе после отката `l=O`: ссылка из адресной строки показывает то, что на экране, и перезагрузка той же вкладки (адрес важнее сохранённого выбора) остаётся на OSM без повторной ошибки.

### Сохранённый выбор у тех, кто уже заходил **[агент]**

Приложение сохраняет выбор при каждом старте (`persist` в `bindAppStore`), поэтому у всех, кто открывал `/` до этого change, в `nakarte-web:layers` записана подложка `O`, и у них останется OpenStreetMap. Это требование «сохранённый выбор важнее умолчания»: автоматическую запись от выбора пользователя не отличить. Владельцу — переключить слой вручную или открыть сайт в приватном окне.

### Проверка ключа: workflow `tracestrack check` **[агент]**

`prod check` по спеке `clone-monitoring` не ходит в чужие сайты, поэтому — отдельный ежедневный workflow по образцу `strava heatmap check`: тайл Тбилиси через прокси с `Origin` клона. `200 image/*` — зелёный; `503` (ключ не задан) — предупреждение `::warning::`, зелёный, пока владелец не завёл ключ; остальное (`403` — ключ или квота, `429`) — красный, GitHub шлёт письмо. Один кредит в день.

### Тесты

- Unit: каталог (`Tt`, адрес через прокси без `key`, 32 слоя, порядок), `validSelection` и `DEFAULT_SELECTION`, стор (откат и его сброс), `sync` (откат не сохраняется, явный выбор сохраняется; первый заход — `l=Tt`).
- Browser (`App.browser.test.tsx`, `LayerSwitcher.browser.test.tsx`): первый заход — тайлы `Tt`, подпись Tracestrack; `503` на тайлы `Tt` — подложка `O`, тост отката, нет тоста ошибки; `404` — без отката.
- e2e: «Первый заход» и тайлы z8/z13 — по слою `Tt`, `l=O` — по `O`; откат на реальной сборке (`failTiles('Tt')`); тайлы `Tt` подменяет фикстура `network` по шаблону каталога (через адрес прокси), в сеть тесты не ходят.
- Прокси (`workers/cors-proxy`, `workerd`): ключ подставлен и запрос клиента отброшен; без секрета `503` без запроса наружу; прочие пути Tracestrack без ключа; `Location` без ключа; `Cache-Control` по умолчанию и не перезаписан; лимит слоёв для `tile.tracestrack.com`.

## Risks / Trade-offs

- [Квоты не хватит: 100 тыс. тайлов ≈ 700–2000 заходов в месяц] → откат на OSM держит карту рабочей, `tracestrack check` присылает письмо; дальше — тариф Personal (€3.99, 250 тыс.), кеш тайлов в Pages Function с Cache API или свой стиль на OpenFreeMap (backlog).
- [Квоту выбирают чужие: `Origin` подделывается не-браузером, лимит — на IP] → ключ тратится только на растр `topo__`; глобального счётчика нет (как у остальных слоёв прокси); если случится — backlog «кеш и защита тайлов Tracestrack».
- [Некоммерческое использование] → клон — некоммерческий проект владельца; при смене статуса нужен платный тариф Standard.
- [Tracestrack меняет адрес или условия] → слой — одна запись каталога и один шаблон в прокси; откат на OSM работает без правок.
- [Тайл по умолчанию 512 px, а не 256] → картинка лишь чётче; `tileSize: 256` даёт тот же масштаб, кредиты те же; проверить после ключа.

## Migration Plan

1. PR в `master`: `check web`, `check cors proxy`, `check lint` зелёные; ревью диффа субагентом.
2. Merge → `deploy pages` выкатывает `nakarte-cors-proxy` и Pages. До ключа прокси отвечает на тайлы `Tt` `503`, приложение откатывается на OSM с тостом.
3. **Шаг владельца:** завести ключ Tracestrack.
   1. Зарегистрироваться в [консоли Tracestrack](https://console.tracestrack.com/) (тариф Intro, бесплатно).
   2. Создать API-ключ; список `Referer` оставить пустым.
   3. Положить ключ секретом прокси: `npx wrangler@4 secret put TRACESTRACK_KEY` из `workers/cors-proxy` (wrangler залогинен OAuth; команда сама выкатывает версию с секретом).
   4. Проверить: `gh workflow run "tracestrack check"` — зелёный без предупреждения; `/` в приватном окне — тайлы Tracestrack, подпись «Maps © Tracestrack».
4. Откат change — revert и push; секрет можно оставить.
