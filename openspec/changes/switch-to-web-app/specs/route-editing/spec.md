## ADDED Requirements

### Requirement: Разметка маршрута в ссылке, в файлах — только геометрия

Ссылка «Copy link» SHALL нести разметку маршрута вместе с геометрией: трек по ссылке размечен так же, как исходный, а опорные точки размеченного отрезка SHALL NOT пропадать при упрощении линии. Трек без разметки SHALL давать ту же строку трека, что давал старый клиент, а разметка — необязательное поле, которое разборщики `nktk` без него пропускают. Экспорт в файлы SHALL содержать только геометрию линии.

#### Scenario: Открытие ссылки

- **WHEN** трек с проложенными отрезками открыт по ссылке «Copy link»
- **THEN** видны только опорные точки, точки маршрута скрыты, а перетаскивание опорной точки перестраивает её отрезки с их активностями

#### Scenario: Ссылка без маршрута

- **WHEN** у трека нет проложенных и непроложенных отрезков
- **THEN** тело ссылки совпадает с телом старого клиента байт в байт

#### Scenario: Ссылка во время прокладки

- **WHEN** ссылка скопирована, пока отрезок ждал ответа роутера
- **THEN** по ссылке этот отрезок открывается непроложенным

#### Scenario: Экспорт в файл

- **WHEN** проложенный трек сохранён в GPX
- **THEN** в файле только точки линии, без разметки маршрута

## REMOVED Requirements

### Requirement: Ссылка несёт разметку маршрута, файлы — только геометрию

**Reason**: Требование обещало, что ссылку с разметкой открывает старый клиент; старого клиента на сайте больше нет, совместимость ссылок с nakarte.me автора не нужна (решение владельца, архив `record-ui-decisions`).

**Migration**: Требование «Разметка маршрута в ссылке, в файлах — только геометрия»: то же поведение без сценария «Ссылка в старом клиенте».
