# street-view Specification

## Purpose
Панорамы Google Street View в новом приложении клона: режим со слоем покрытия, поиск панорамы по клику, окно панорамы рядом с картой и состояние панорамы в адресе, совместимое со ссылками старого клиента.

## Requirements

### Requirement: Режим Street View

Кнопка Street View на карте и сочетание Alt+P SHALL включать и выключать режим Street View. Во включённом режиме SHALL показываться слой покрытия Google поверх слоёв карты и под треками. Выключение SHALL убирать покрытие и закрывать панораму.

#### Scenario: Включить режим

- **WHEN** пользователь нажимает кнопку Street View
- **THEN** кнопка нажата, на карте слой покрытия Street View над подложкой и оверлеями, треки над ним

#### Scenario: Выключить режим

- **WHEN** открыта панорама, и пользователь снова нажимает кнопку Street View
- **THEN** покрытие и панель панорамы пропадают

### Requirement: Панорама по клику

В режиме Street View клик по карте SHALL искать ближайшую панораму в радиусе 24 пикселей экрана от точки клика и открывать её; если панорамы нет — ничего не менять. Клик, который занят редактором (рисование линии, выбор Join или Shortcut, постановка точки трека, открытое меню), SHALL NOT искать панораму.

#### Scenario: Панорама найдена

- **WHEN** режим включён, и пользователь кликает рядом с дорогой с покрытием
- **THEN** открывается панель с панорамой ближайшей к клику точки, на карте метка панорамы

#### Scenario: Панорамы рядом нет

- **WHEN** режим включён, и пользователь кликает далеко от покрытия
- **THEN** панель не открывается, открытая панорама не меняется

#### Scenario: Рисование линии в режиме Street View

- **WHEN** режим включён, идёт рисование линии, и пользователь кликает по карте
- **THEN** в линию добавляется опорная точка, панорама не ищется

### Requirement: Панель панорамы

Панорама SHALL открываться в панели под картой, над профилем высот, если он открыт; кнопка профиля высот, атрибуция и тосты SHALL оставаться над ними. В панели SHALL быть кнопка закрытия; закрытие оставляет режим включённым. На карте SHALL быть метка позиции панорамы, повёрнутая по направлению взгляда; переход в другую точку панорамы SHALL сдвигать метку, а при уходе за край — карту.

#### Scenario: Направление взгляда

- **WHEN** пользователь поворачивает панораму на восток
- **THEN** метка на карте смотрит на восток

#### Scenario: Панорама и профиль высот

- **WHEN** открыт профиль высот, и пользователь открывает панораму
- **THEN** обе панели видны, панорама над профилем, кнопка профиля высот над панорамой

#### Scenario: Закрыть панораму

- **WHEN** пользователь закрывает панель панорамы
- **THEN** панель и метка пропадают, покрытие остаётся, следующий клик снова ищет панораму

### Requirement: Street View в адресе

Режим и панорама SHALL записываться в адрес параметром старого клиента `n2=`: `_g` — режим включён, `_g/g/lat/lng/heading/pitch/zoom` — с открытой панорамой. Адрес с `n2=` и старым `n=lat/lng/heading/pitch/zoom` SHALL открывать режим и панораму; `n=` после чтения SHALL заменяться на `n2=`. Коды удалённых провайдеров и неверные значения SHALL NOT ломать загрузку. «Copy link» SHALL сохранять `n2=`.

#### Scenario: Ссылка с панорамой

- **WHEN** приложение открыто по адресу с `n2=_g/g/41.693000/44.780000/90.0/0.0/1.0`
- **THEN** режим включён, панорама открыта в этой точке, взгляд на восток

#### Scenario: Старая ссылка n=

- **WHEN** приложение открыто по адресу с `n=41.693000/44.780000/90.0/0.0/1.0`
- **THEN** открывается та же панорама, в адресе вместо `n=` — `n2=_g/g/…`

#### Scenario: Удалённый провайдер

- **WHEN** приложение открыто по адресу с `n2=_w` или `n2=wmc`
- **THEN** карта открывается без ошибок, режим Street View выключен

### Requirement: Maps JavaScript API по требованию

Maps JavaScript API SHALL загружаться только при первом поиске панорамы или открытии панорамы из адреса, а не при загрузке приложения и не при включении режима: слой покрытия — тайлы без API. Ошибка загрузки API SHALL давать тост `Street View is unavailable`.

#### Scenario: Режим без панорамы

- **WHEN** пользователь включает режим Street View и не кликает по карте
- **THEN** запросов к `maps.googleapis.com/maps/api/js` нет, тайлы покрытия запрашиваются

#### Scenario: API не загрузился

- **WHEN** загрузка Maps JavaScript API завершилась ошибкой, и пользователь кликает по карте в режиме
- **THEN** появляется тост `Street View is unavailable`, карта работает

### Requirement: Ключ Google в новом приложении

Новое приложение SHALL загружать Maps JavaScript API с ключом из переменной сборки `VITE_GOOGLE_MAPS_API_KEY`, а без неё — с пустым ключом. С пустым ключом панель панорамы SHALL показывать панораму в нормальных цветах без водяного знака и окна режима разработки Google, как старый клиент (capability `clone-hosting`, «Street View без ключа без режима разработки»); с ключом — как её рисует Google.

#### Scenario: Сборка без ключа

- **WHEN** приложение собрано без `VITE_GOOGLE_MAPS_API_KEY`
- **THEN** Maps JavaScript API запрашивается с пустым `key=`, правила режима без ключа применяются к панели панорамы

#### Scenario: Сборка с ключом

- **WHEN** приложение собрано с `VITE_GOOGLE_MAPS_API_KEY`
- **THEN** Maps JavaScript API запрашивается с этим ключом, правила режима без ключа не применяются
